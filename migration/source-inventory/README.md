# Source inventory

이 폴더의 파일은 이전 작업의 기준표다. 원문 플랫폼의 글 수, 고유 ID, 원주소, 공개 범위, 카테고리, 게시일과 미디어 관계를 기록한다.

- `naver-posts.json`: 2026-08-23 소유자 글 저장 화면에서 읽은 직접 작성 글 432개
- `tistory-posts.json`: 티스토리 공개 글 164개와 미디어 814개의 이전·해시 기준표
- `naver-posts.json`은 비공개 글 제목을 포함하므로 로컬 전용이며 Git에 넣지 않는다.
- 공개 범위가 `private` 계열인 데이터는 공개 콘텐츠 폴더로 자동 복사하지 않는다.
- 인벤토리의 수치와 실제 생성 파일 수가 다르면 이전을 완료로 표시하지 않는다.
