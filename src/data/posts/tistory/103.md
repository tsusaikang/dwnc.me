<p data-ke-size="size16">웹 개발을 하다 보면 자주 등장하는 개념들 중에서 '도구(Tool)', '라이브러리(Library)', '프레임워크(Framework)'라는 말이 있습니다. 이 세 가지는 비슷한 상황에서 등장하기 때문에 초보자들에게 혼란을 줄 수 있는데요, 이번 글에서는 이 용어들이 각각 무엇을 의미하고, 어떤 차이가 있는지 쉽게 정리해보겠습니다.</p>
<h2 data-ke-size="size26">1. 도구(Tool)</h2>
<p data-ke-size="size16"><b>도구는 특정 작업을 쉽고 효율적으로 수행하도록 돕는 소프트웨어나 프로그램</b>입니다. 독립적으로 특정 기능이나 작업을 처리하기 위해 쓰이며, 필요할 때마다 꺼내 쓰는 형태로 활용됩니다.</p>
<h3 data-ke-size="size23">도구의 예시</h3>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li><b>Git</b>: 소스코드 버전 관리</li>
<li><b>npm, yarn</b>: 자바스크립트 라이브러리 설치 및 관리</li>
<li><b>Webpack, Babel</b>: 자바스크립트 코드를 변환 및 최적화</li>
<li><b>Docker</b>: 애플리케이션 배포 및 환경 관리</li>
</ul>
<h2 data-ke-size="size26">2. 라이브러리(Library)</h2>
<p data-ke-size="size16"><b>라이브러리는 자주 사용되는 기능을 미리 만들어놓은 코드의 집합</b>입니다. 개발자가 본인의 코드에서 필요할 때 가져와 사용합니다. 즉, 개발자가 직접 호출하여 기능을 사용하는 방식입니다.</p>
<h3 data-ke-size="size23">라이브러리 사용 예시</h3>
<pre class="javascript"><code>// 예시: Axios 라이브러리를 이용한 HTTP 요청
import axios from 'axios';

axios.get('https://example.com/api/data')
     .then(response =&gt; console.log(response.data));
</code></pre>
<h3 data-ke-size="size23">주요 라이브러리 예시</h3>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li><b>React</b>: UI 화면 구성</li>
<li><b>Axios</b>: HTTP 요청 처리</li>
<li><b>Lodash</b>: 자바스크립트 유틸리티 함수 모음</li>
</ul>
<h2 data-ke-size="size26">3. 프레임워크(Framework)</h2>
<p data-ke-size="size16"><b>프레임워크는 애플리케이션 개발의 전체적인 틀과 구조를 미리 정해놓은 코드들의 집합</b>입니다. 프레임워크를 사용할 경우 개발자는 정해진 구조 안에서 코드를 작성하게 됩니다. 즉, 프레임워크가 정한 규칙과 틀 안에서 개발자가 특정 부분을 채워나가는 방식입니다.</p>
<h3 data-ke-size="size23">프레임워크 사용 예시</h3>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li><b>Angular</b>: 구글이 만든 구조화된 웹 개발 프레임워크</li>
<li><b>Vue.js</b>: 직관적이고 표준화된 구조를 제공하는 프론트엔드 프레임워크</li>
<li><b>Django(파이썬)</b>: 웹 개발을 위한 명확한 구조와 기능 제공</li>
</ul>
<h2 data-ke-size="size26">간단한 비유로 이해하기</h2>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li><b>도구(Tool)</b>: 망치나 드라이버와 같은 공구 (필요한 순간에 꺼내 씀)</li>
<li><b>라이브러리(Library)</b>: 레고 블록 (필요한 블록을 골라 자유롭게 조합해서 씀)</li>
<li><b>프레임워크(Framework)</b>: 프라모델 키트 (정해진 틀과 순서에 따라 조립해야 함)</li>
</ul>
