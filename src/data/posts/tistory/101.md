<p style="color:#000000;text-align:start" data-ke-size="size16"><b>— 풋(Foot)·킷(Kit)·바(Bar) 3단 구조와 모델명 숫자 읽는 법</b></p>
<blockquote style="background-color:#f7f7f7;color:#333333;text-align:start" data-ke-style="style1">
<p data-ke-size="size16">“7104, 7107, 7206, 7113, 9593… 툴레 숫자는 왜 이렇게 많을까?” 결론부터:<span> </span><b>툴레 모델번호는 “무엇을(풋/바) + 어떤 세대(Rapid/Evo/Edge) + 어떤 지붕/어떤 길이”</b><span> </span>3가지 정보만 담고 있습니다. 이 규칙만 알면 숫자만 보고 내 차에 맞는지 판단할 수 있습니다.</p>
</blockquote>

<h2 id="모델번호-숫자-읽는-법-정리-규칙" style="color:#000000;text-align:start" data-ke-size="size26">5. 모델번호 숫자 읽는 법 (정리 규칙)</h2>
<pre class="angelscript" style="background-color:#2d2d2d;color:#f5f5f5;text-align:start"><code>풋 (Foot)
  751 / 753 / 754 / 757 / 775  → Rapid (구형)
  710 + [4·5·6·7]              → Evo    (Raised·Clamp·Flush·Fixpoint 순)
  720 + [4·5·6·7]              → Edge   (동일 순서)

바 (Bar)
  711 + [1~5]  → WingBar Evo   → 108·118·127·135·150 cm
  712 + [1~5]  → SquareBar Evo → 108·118·127·135·150 cm
  721 + [1~6]  → WingBar Edge  (사이즈 코드)
  89  + [1~3]  → SlideBar      → 127·144·162 cm
  39  + [0~5]  → ProBar Evo    → 120·135·150·175·200·220 cm
  96x          → 구형 WingBar  (960·961·969·962·963 = 108·118·127·135·150)

색상 (풀 6자리 코드 뒤 2자리)
  ...00 = 실버 / ...20 = 블랙</code></pre>
<p style="color:#000000;text-align:start" data-ke-size="size16"><b>외우기 쉬운 한 줄</b>:<span> </span>710x = Evo 풋,<span> </span>720x = Edge 풋,<span> </span>711x = 윙바,<span> </span>712x = 사각바,<span> </span><b>끝자리 4→5→6→7 = 돌출레일→민자→밀착레일→고정점</b>.</p>

<h2 id="선택-순서-5단계-체크리스트" style="color:#000000;text-align:start" data-ke-size="size26">6. 선택 순서 (5단계 체크리스트)</h2>
<ol style="list-style-type:decimal;color:#000000;text-align:start" data-ke-list-type="decimal">
<li><b>지붕 타입 확인</b><span> </span>→ Raised / Flush / Fixpoint / Naked / Gutter 중 하나</li>
<li><b>세대 결정</b>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li>신품·범용성·액세서리 확장 →<span> </span><b>Evo (710x)</b></li>
<li>외관·저소음 최우선, 짧은 바 OK →<span> </span><b>Edge (720x)</b></li>
<li>이미 구형 바 보유 →<span> </span><b>Rapid (3자리)</b><span> </span>중고 매칭</li>
</ul>
</li>
<li><b>킷 필요 여부 확인</b><span> </span>→ Flush/Fixpoint/Naked면<span> </span><b>차종별 킷 필수</b></li>
<li><b>바 종류·길이 선택</b>
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li>자전거 2대 이상 또는 루프박스 병행 →<span> </span><b>WingBar Evo 127cm 이상</b></li>
<li>자전거 1대 + 여유 → 118~127cm</li>
</ul>
</li>
<li><b>적재 한도 확정</b><span> </span>→ 아래 3개 값 중<span> </span><b>가장 낮은 값</b>이 실제 한도
<ul style="list-style-type:disc" data-ke-list-type="disc">
<li>① 차량 매뉴얼의 지붕 허용 하중 (국산차 대개<span> </span><b>70~100kg</b>)</li>
<li>② 풋 허용치 (75 or 100kg)</li>
<li>③ 바 허용치 (75~100kg)</li>
</ul>
</li>
</ol>

<h2 id="실전-팁-흔한-실수" style="color:#000000;text-align:start" data-ke-size="size26">8. 실전 팁 &amp; 흔한 실수</h2>
<h3 id="이건-꼭-알아두기" style="color:#000000;text-align:start" data-ke-size="size23">✅ 이건 꼭 알아두기</h3>
<ul style="list-style-type:disc;color:#000000;text-align:start" data-ke-list-type="disc">
<li><b>토크 키를 끝까지 쓰세요.</b><span> </span>Evo/Edge 풋에 동봉된 토크 리미터 키는<span> </span><b>“딸깍” 소리가 날 때가 적정 토크</b>입니다. 더 조이면 나사산이 망가집니다.</li>
<li><b>락은 대부분 기본 포함.</b><span> </span>현행 Evo·Edge 풋은<span> </span><b>One-Key 락이 기본 동봉</b>되어 차량에 고정됩니다. 다만<span> </span><b>자전거 캐리어·루프박스까지 같은 열쇠로 통일</b>하려면 One-Key 코어 세트를 별도 구매해 교체하면 됩니다.</li>
<li><b>샤크핀 안테나·선루프 간섭</b>을 미리 확인하세요. 낮은 풋(Edge, 775, 753)은 간섭 확률이 올라갑니다.</li>
<li><b>바 간격</b>은 액세서리 설명서의 최소 간격(대개 60~70cm)을 지켜야 합니다. 짧은 지붕 차량은 이 조건 때문에 캐리어 장착이 막히기도 합니다.</li>
</ul>

<h2 id="초-요약" style="color:#000000;text-align:start" data-ke-size="size26">9. 30초 요약</h2>
<ul style="list-style-type:disc;color:#000000;text-align:start" data-ke-list-type="disc">
<li><b>루프랙 = 풋 + (킷) + 바.</b><span> </span>세 가지를 모두 맞춰야 합니다.</li>
<li><b>풋 번호</b>:<span> </span>710x<span> </span>= Evo(현행 주력),<span> </span>720x<span> </span>= Edge(프리미엄),<span> </span>3자리<span> </span>= Rapid(구형)</li>
<li><b>끝자리 규칙</b>:<span> </span><b>4=돌출레일 / 5=민자 / 6=밀착레일 / 7=고정점</b></li>
<li><b>바 번호</b>:<span> </span>711x<span> </span>= WingBar Evo,<span> </span>712x<span> </span>= SquareBar Evo,<span> </span>721x<span> </span>= WingBar Edge</li>
<li><b>길이 규칙</b>:<span> </span>711x·712x의 끝자리 1~5 =<span> </span><b>108·118·127·135·150 cm</b></li>
<li><b>호환 함정</b>: WingBar Edge는<span> </span><b>Edge 풋 전용</b>. 다른 바와 절대 안 섞임</li>
<li><b>적재 한도</b>: 차량 매뉴얼 · 풋 · 바<span> </span><b>세 값 중 최저값</b></li>
</ul>
