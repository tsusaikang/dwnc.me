- 현재 주소 변환으로 이동 주소는 `/posts/581`이 됐지만 카드 문구는 과거 저장값이 유지됐다. 요약의 Threads URL도 저장된 카드 설명이며 581번 글을 외부 글로 분류한 결과가 아니다. 이번 수정에서는 요약을 새로 생성하지 않는다.
