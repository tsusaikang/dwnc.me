# 사진 편집 중첩 방지와 한정 작업본 정리

- 요구사항: `DWNC-CORE-029`, `PLAN-09`.
- 상태: 운영 구조 조회·요구사항 등록 완료, 로컬 재현·수정 후 동작 확인 완료. 최종 빌드·배포·한정 작업본 정리·전수조사는 아직 완료하지 않았다.

## 요청과 이번 운영 조회

사용자는 #599에서 사진 편집 적용 시 테두리가 반복해 늘고 텍스트가 그 안으로 들어갔다고 알렸다. 텍스트는 직접 바깥으로 꺼내 저장했다고 설명했다.

메인이 이번 작업을 위해 최신 운영 API와 관리자 DOM을 읽었다. 마지막 저장 23:36:05 KST이며 당시 작업본과 공개 내용이 같았다. 빈 figure 2개와 문단 3개, 같은 형태의 figure 4겹 중첩을 확인했고 가장 안쪽에는 사진 1개와 캡션 1개가 있었다. 이 구조는 조회 시점 관측이며 실제 정리 직전에 다시 조회한다. 운영 고유 제목·본문·이미지 경로는 문서·Git에 기록하지 않는다.

## 수정 범위와 보존

사진 편집 적용은 선택한 정확한 DOM 요소를 교체하도록 고친다. `execCommand('insertHTML')`로 선택 영역에 다시 삽입하면서 기존 figure 안에 새 figure가 들어가는 경로를 보완한다. 캡션을 바꾸지 않은 경우 기존 캡션 내부 서식을 유지하고 사진 뒤 텍스트·주변 문단도 보존한다.

재발 방지 확인과 운영 반영 뒤 해당 글의 최신 작업본·반영본을 다시 조회하고 현재 revision을 기준으로 확정된 빈 틀 2개·중복 바깥 틀 3개만 정리한다. 사용자 수정으로 구조가 달라졌으면 기존 숫자를 강제하지 않는다. 가장 안쪽 사진·캡션과 사진 밖 본문·기존 서식을 보존한 작업본만 저장하고 공개 반영하지 않는다. 다른 글·원본 사진·공개 상태는 변경하지 않는다.

## 역할과 남은 확인

구현과 독립 읽기 검토는 하위 에이전트가 맡고 메인은 최신 운영 조회·사용자 세션에 묶인 브라우저·통합·Git 배포·해당 작업본 정리를 맡는다.

로컬 합성 재현·반복 적용·실행 취소/다시 실행·저장/재열기·사진 뒤 텍스트를 확인하고 최종 소스를 기존 Git 자동 배포로 양쪽에 반영한 뒤 운영을 읽기 확인한다. 실제 글로 재현 시험을 하지 않는다. 코드 수정 완료와 해당 글 작업본 정리 완료를 구분해 기록하며 현재 위치·완료조건은 [공식 상태](../../PROJECT_STATE.md) 및 [현재 요구사항](../REQUIREMENTS.md)을 따른다.

## 추가 요청: 다른 글의 같은 문제 전수조사

사용자가 수정 후 다른 글도 전수조사하도록 요청했다. 이번 작업 중 운영 DB/API에서 조회한 현재 전체 목록과 모든 작업본·공개본을 기준으로 새 글·사용자 변경분을 포함하고 조회 시점·범위를 기록한다. 정상적인 중첩·사진 묶음·캡션과 손상 징후를 구분해 확정 문제·검토 필요·접근 미확인으로 보고한다.

다른 글 일괄 수정은 조사 승인에 포함되지 않는다. 운영 자료를 읽지 못한 범위는 실제 장애와 함께 미확인으로 남기고 과거 이관 덤프로 대신하지 않는다. 해당 글의 확정된 빈 틀·중복 바깥 틀 작업본 정리는 기존 범위로 진행한다. 운영 고유 내용 없이 조사 결과와 남은 판단만 공식 기록에 남긴다.

## 로컬 재현·수정 후 확인

메인이 내장 브라우저의 로컬 합성 편집기에서 사진과 카드가 인접한 구조를 확인했다. 수정 전 사진 편집을 한 번 적용하면 figure 수가 2개에서 3개로 늘고 중첩 figure가 2개 생기며 사진이 카드 안으로 들어가는 현상을 재현했다.

수정 후 같은 조건에서 캡션 변경을 네 번 적용해도 figure 2개·중첩 0을 유지했다. 사진 뒤 `x` 입력이 사진 밖에 남고 실행 취소/다시 실행·자동저장·새로고침 후에도 구조·캡션·뒤 입력을 유지하는 것을 확인했다. 이는 로컬 합성 자료 시험이며 운영 글을 재현 시험에 쓰지 않았다.

코드 담당의 관련 검사는 통과했고 최종 빌드는 대기 중이다. D1 전수조회는 첫 인증 오류 `7403`을 해결 중이므로 아직 전체 목록·작업본·공개본 검사를 완료하지 않았다. 이번 로컬 재발 방지 확인을 운영 배포·해당 글 작업본 정리·전수조사 완료로 확대하지 않는다.
