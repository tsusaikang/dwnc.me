# 사진 그룹 설명과 공통 높이

`DWNC-CORE-036`, 2026-09-30. 사용자 요청: 나란히 배치한 두세 장의 설명은 그룹에 속하며 서로 다른 종횡비도 높이를 맞춘다.

## 변경과 결정

- 어느 사진을 골라도 같은 `그룹 설명 편집`을 열고 설명은 묶음 아래 한 영역에 표시한다. 대체텍스트는 선택 사진에만 적용한다.
- 기존 사진별 설명은 링크·강조·명시 정렬을 보존하여 그룹 설명에 합친다. 한 장 빼내면 설명은 남은 그룹에 유지하고, 전체 해제하면 마지막 사진 아래에 한 번 보존한다. 설명 외의 기존 본문을 버리지 않도록 구조 검사를 유지했다.
- 사진의 가로/세로 비율로 너비를 배분하여 공통 높이를 만든다. 원본 확대·잘림·비율 변형 없이 원본 최소 높이를 상한으로 삼는다. 읽기·이미지 로드 때 계산하므로 기존 저장 그룹도 새로 열면 적용된다.
- 편집기·미리보기·공개 표시가 같은 규칙을 사용한다. 공개 그룹은 좌측 메뉴를 제외한 실제 글 영역 안에 들어오도록 제한한다.
- 실제 글·작업본·미디어 일괄 쓰기 및 공개 전환은 하지 않았다. 메인이 사용자 세션이 필요한 자체 브라우저 조회와 로컬 화면 시험을 담당하고 구현·독립 검토는 하위 에이전트에 위임했다.

## 검증

- 운영 관리자 API가 반환한 최신 작업본을 읽기 전용으로 확인했다. 두 장 그룹 세 개와 1920×2560·2560×1920 혼합 사례의 기존 구조를 확인했으며 원문은 기록하지 않았다. 사용자 수정 중일 수 있으므로 조회 이후 상태를 고정하지 않았다.
- 전체 `npm run editor:test` 통과. 설명 병합/서식·정렬, 사진 이동·분리·해제, 설명 편집, 저장/재열기, 실행 취소 회귀를 보완했다. 독립 검토에서도 관련 다섯 검사 통과, 남은 구체 결함 없음.
- 최종 `npm run cloudflare:build:source` 통과. 공개 산출물 검사와 비공개 누출 검사 통과.
- 실제 자체 브라우저 로컬 합성 사진(600×800, 1000×600, 800×800): 세 장 묶기·다른 사진에서 같은 설명 열기·저장 후 재열기·한 장 빼내기·실행 취소 확인. PC 미리보기 높이 약242.34px, 모바일 미리보기 약95.41px로 동일(서브픽셀 반올림 오차 이내).
- 최종 두 장 그룹 편집기 높이491.58px, 그룹/본문 중심 일치. 로컬 공개 처리기에서 1265px 화면의 메뉴176px를 제외한 글 영역1089px, 그룹1045px·좌우 여백22px, 사진 높이427.445px 동일·수평 넘침 없음. 793px 화면도 그룹749px·높이304.96px·넘침 없음.
- 실제 운영 콘텐츠에 시험 입력은 하지 않았다. 공개 시험은 localhost 합성 데이터에 한정했다.

## 운영 전달

최종 기능 코드와 기록의 Git 푸시 및 양쪽 자동 배포 확인을 진행한다. 배포 전부터 열려 있던 편집기는 작업본 저장 완료 확인 후 새로 열어야 새 코드가 적용된다.
