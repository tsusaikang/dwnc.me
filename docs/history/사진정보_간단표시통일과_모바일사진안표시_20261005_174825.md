확인된 Display P3와 해당 ICC 설명의 중복은 합치고 다른 프로필은 함부로 지우거나 동일시하지 않는다. HDR 게인맵 방식은 한 문구로 합치고 실제 기록 수치만 표시한다. 좁은 PC 사진의 말풍선과 무배경/글자 그림자·실제 부족할 때만 스크롤 정책을 유지한다. 모바일 정보는 별도 상세 조회나 헤더 공간을 만들지 않고 사진/번호선택과 겹치지 않게 배치한다.

구현·관련 회귀·독립 검토·최종 빌드·PC/모바일 실제 표시 및 본문/저장 보존·Git 원격 동기화가 완료조건이다. `0f2e753`·미커밋 없음에서 시작한다. 실제 글·사진·작업본 쓰기·공개 전환·권한 변경은 없다.

## 표시 축약 근거

[W3C Display P3 정의](https://www.w3.org/TR/css-color-4/#predefined-display-p3)는 DCI-P3 원색·D65 백색점·sRGB 전달 곡선을 설명한다. 이미 판독된 colorSpace=Display P3와 정확한 프로필 설명 `sRGB EOTF with DCI-P3 Color Gamut` 조합만 Display P3 한 줄로 합친다. 미확인 색공간이나 custom 프로필은 추정하지 않는다. 별도 항목명을 빼도 표준명과 HDR 게인맵이라는 값으로 종류를 구분하게 하며, 모든 사용자가 전문 용어의 의미를 아는 것으로 단정하지 않는다.
