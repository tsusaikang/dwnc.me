## 최근 완료와 사용자 동작

**글 전체 사진 순서 미리보기(`DWNC-CORE-039`)를 구현·배포했다.** 본문을 길게 오가지 않고 사진 배열을 보고 이동할 최종 번호를 고를 수 있다.

1. 본문에서 옮길 사진이나 사진 번호를 눌러 선택한다.
2. `전체 사진 순서`를 누른다. 현재 순서대로 축소 사진과 번호가 나오며 그룹 사진은 같은 줄에 놓인다. 옮길 사진은 파란 테두리와 문구로 구분한다.
3. 원하는 최종 번호의 사진을 누른다. 창이 닫히고 `옮길 번호`만 채워진다. 이 단계에서는 사진을 이동하지 않는다.
4. `번호로 이동`을 누르거나 입력칸에서 Enter를 입력한다. 이동 후 번호가 다시 매겨진다.

사진 전체를 잘리지 않게 보여 주고, URL 카드 썸네일은 사진 목록에서 제외한다. 닫기·Escape와 입력칸/열기 버튼으로 포커스 복귀를 지원한다. 미리보기 UI와 사진 번호는 본문 밖에 있어 저장·공개 본문에 들어가지 않는다.

**기존 번호 이동(`DWNC-CORE-038`)의 동작과 한계는 유지한다.** 같은 그룹은 재정렬하고 다른 그룹 내부 순번은 필요한 경계에서 행을 나눠 독립 사진으로 놓는다. 공통 설명은 원래 앞쪽 행에, 개별 설명은 해당 사진에 보존하며 한 번의 실행 취소로 되돌린다. 잘못된 번호나 같은 순번은 본문을 바꾸지 않는다. 일반 문단·표 하나에 여러 사진이 섞인 내부 위치는 서식 보존 안내 후 거부한다. 번호를 직접 입력하는 방법과 기존 드래그·방향키 이동도 유지한다.

## 재개 시 유지할 원칙

- 자동저장은 작업본 저장이며 공개 반영과 별개다. 실제 콘텐츠 쓰기는 최신 revision 충돌 방지로 사용자 수정을 보호하고 미공개 작업본 덮어쓰기·요청 없는 공개를 하지 않는다. 기존 실제 글을 기능 시험에 사용하지 않는다.
- 브라우저는 Codex 자체 브라우저만 사용한다. 새 세션·탭·프로젝트에서는 로그인·대상 계정을 확인하고, Cloudflare 작업 전 계정 확인값을 프로젝트 기준과 대조한다. 로그인 정보는 사용자가 직접 입력하며 비밀값·비공개 원문·로컬 인증은 Git과 인수인계에 넣지 않는다.
- 메인은 조정·통합·공식 상태·사용자 세션을 맡고 주요 실무는 하위 에이전트에 위임한다. 사용자 브라우저 등 접근 불가가 확인되면 메인이 필요한 동작만 직접 수행한다. 새 주요 단계 전에 통합·검증·공식 상태 갱신·보고까지 현재 컨텍스트에서 마칠 수 있는지 확인한다.
- 마감에는 저장소 관리 대상 변경을 공식 상태에 반영하고 커밋·푸시한다. 기존 미커밋 작업은 확인해 보존한다. 문서만 푸시해도 Cloudflare 자동 빌드가 시작될 수 있으며 기록 전달과 기능·콘텐츠 변경을 구분한다. 삭제·외부 전송·권한·비용·공개 전환의 기존 승인 범위를 임의 확대하지 않는다.
- 승인된 Git 자동 배포 경로를 따르고 직접 배포·DNS/route·권한 변경으로 우회하지 않는다. Cloudflare 파일 전달의 `redirect: 'manual'`과 응답 검사 규칙을 유지한다. 로컬 시험·빌드 통과만으로 운영 성공을 단정하지 않는다.
