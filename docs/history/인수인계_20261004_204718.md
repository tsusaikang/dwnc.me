# dwnc.me 인수인계

작성: 2026-10-04 KST

## 목적과 재개 기준

기존 글·사진·서식·주소와 공개/작업본 구분을 보존하며 블로그를 지속 운영한다. 이번 요청은 인수인계 준비이며 새 기능 구현·운영 콘텐츠 수정은 포함하지 않는다. 착수 시 저장소는 깨끗했고 `main`의 마지막 커밋은 `c28c1b7`이었다. 이 문서 작성 이후에는 원격 main의 최신 문서까지 받아 재개한다.

먼저 [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../../PROJECT_STATE.md), [현재 요구사항](../REQUIREMENTS.md)을 읽는다. 현재 상태가 과거 대화보다 우선하며, 완료 근거는 해당 상태 문서에서 연결한 이력만 필요한 부분을 읽는다.

## 남은 작업과 착수 조건

- CORE-012 결함 6건: 사용자 후속 착수 지시 대기. 사진 삭제 undo/redo, CSS 배경 사진 접근, 검색 오류·늦은 응답, 초안 생성·업로드 재시도 중복이다. [세부 완료조건](../결함_보완_요구사항_20260909_223512.md)에 따른다. 최신 사진 그룹 수정이 이 별도 6건 전체의 완료를 뜻하지 않는다.
- 외부 위키 1개: 연결 복구 또는 동일 원문 확보 뒤 재확인. Instagram 이용 불가 안내는 원문 복구가 아니다.
- 독립 사본 위치·비공개 백업 정책(OPS-003), 공유·스크랩 추정 10개 처리(OPS-001): 사용자 선택 대기.
- 접근성·추가 탐색(P2-001): 별도 요청 시 착수. 댓글·방명록·구독·팀블로그는 제외, 광고는 후순위다.
- 로그인 후 관리자 열람의 조회수 제외: 기존 쿠키 조건에 연결되지만 실제 집계 전후 비교는 하지 않았다. 필요 시 별도로 확인한다.
- 실제 OS 한글 IME·물리 단축키·휴대폰 터치·일부 좁은 화면·전체 접근성·대규모 부하 등 미검증 범위는 공식 상태대로 유지한다.

다음 작업은 새 사용자 요청의 범위를 먼저 적용하는 것이다. 인수인계 요청만으로 위 대기 항목의 구현·배포나 실제 글 수정에 착수하지 않는다.

## 유지할 결정과 주의사항

- 자동저장과 공개 반영은 별개다. 실제 콘텐츠 작업 전 최신 운영 DB/API의 반영본과 작업본을 읽고 revision 충돌 방지를 유지한다. 과거 이관 덤프나 `src/data/posts`로 현재 콘텐츠를 대신하지 않는다.
- 기존 실제 글을 시험 변경·공개하지 않는다. 승인된 비공개 합성 시험 글과 허용 범위는 공식 상태를 따른다. 사용자 편집 중인 탭을 임의 새로고침하지 않는다.
- 브라우저는 Codex 자체 브라우저만 사용한다. Cloudflare 대시보드와 블로그 로그인은 별개이며 새 세션에서 계정·접근 상태를 확인한다. 비밀값이나 비공개 원문을 Git·인수인계에 넣지 않는다.
- 공개 `dwnc-me`와 관리자 `dwnc-me-admin`은 Git 자동 배포를 사용한다. main 푸시는 문서만 바뀌어도 빌드를 시작할 수 있다. 직접 배포·권한 변경·삭제·콘텐츠 공개의 승인 범위를 임의 확대하지 않는다.
- Cloudflare 런타임은 `redirect: 'error'`를 지원하지 않아 실제 장애가 있었다. 관련 수정은 `manual`과 응답 검사로 처리한다. 로컬 모의시험과 배포 성공만으로 실제 운영 성공을 단정하지 않는다.
- 주요 실무는 하위 에이전트에 위임하고 메인은 통합·상태 갱신·사용자 브라우저 동작을 맡는다. 마감 시 저장소 관리 대상 변경을 커밋·푸시한다.
- 작성 스킬 관리 이전은 [별도 인수인계](스킬관리프로젝트_인수인계_20260924_141207.md)를 따른다. 개인용 설치본과 새 관리 프로젝트 생성·이전 완료를 혼동하지 않는다.
