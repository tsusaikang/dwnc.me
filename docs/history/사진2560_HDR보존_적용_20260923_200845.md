# 신규·기존 첨부 사진 2560px·HDR 보존 적용

기준: 2026-09-23 KST. 요구사항 `DWNC-CORE-032`. 최종 운영 결과는 [공식 상태](../../PROJECT_STATE.md)를 따른다.

## 결정과 구현

사용자가 긴 변2560px를 확정하고 새 블로그 생성 후 기존 업로드와 이후 편집기 업로드 모두 적용하도록 요청했다. 품질80, 종횡비 유지·무확대, 목표500KB~1MB는 강제 상한이 아니다. 과거 네이버·티스토리 이관 사진은 제외한다.

파일 선택과 클립보드는 `src/lib/admin-image-upload.ts`의 같은 준비 경로를 사용한다. JPEG는 Google libultrahdr1.4.0·libjpeg-turbo3.0.1을 Emscripten4.0.14로 빌드한 WASM과 module Worker로 처리한다. HDR/SDR를 같은 선형광 Lanczos 방식으로 줄이고 HDR gain map을 재생성한다. 원본 ICC와 HDR 표시 밝기 범위를 유지한다. JPEG 외 정지 이미지의 실제 투명 여부·애니메이션 보존·25MiB 입력 제한·작은 입력 팽창 방지를 유지한다. 지원 밖 색상/HDR은 명시적으로 중단하며 SDR로 우회하지 않는다. [지원 범위와 재현](../../scripts/image-codecs/README.md).

실행 자산은 `public/image-codecs/`6개, 허용목록은 `src/data/image-codec-assets.json`이다. 공개 자산과 관리자 고정 프록시로 같은 출처에서 읽으며 인증 헤더·쿠키는 공개 호스트에 전달하지 않는다. worker/script/WASM에 필요한 CSP만 확장했다. source-only 빌드는 정확한6개를 복사한다. 개발 중 private 벤더 소스가 Astro 검사를 오염시키지 않도록 tsconfig에서 migration/private·tmp를 제외했다.

## 기존 사진 조사와 적용 준비

이번 Cloudflare D1 콘솔에서 native_media23개110207991bytes, legacy_media의native경로2731개1316018054bytes를 조회했다. 경로만으로 신규사진을 구별할 수 없다. 이관기는 원글 발행일을 첨부 생성일로 기록한다. legacy2731개 전부 두 날짜가 같고 최신2022-09-13이어서 제외했다.

현재 공개597/599/600/601/602응답을 읽어17개103773480bytes를 받았다. 실제투명0, 5991개+6009개가2560초과HDR/P3다. 나머지7개는이미기준이하. DB와공개목록차이3개는작업본·대표사진·미참조를추가대조해야하며598은기존비공개합성시험3개로구별한다.

기존native의id/public_path를유지하고 새object_key/sha/bytes/mime만 CAS교체하는 방식을 실제서빙모듈+합성DB로 확인했다. 본문·사용자편집·revision·작업본·공개정책·대표사진은 바꾸지 않는다. 모든 대상의현재metadata가맞을때만단일UPDATE가성공하며 replay/stale/newkey충돌을거부한다. 준비도구 `scripts/prepare-native-media-replacement.mjs`는 SQL생성만하며운영실행은없다.

기존CLI인증은다른프로젝트계정의제한된권한으로블로그D1조회7403오류다. 기존인증을덮어쓰지않고블로그전용R2/D1인증연결을사용자에게질문했다. 새사진후보·원본·공개응답·상세목록은 `migration/private/native2560_20260923/`에만보존한다. 이 기록 작성 시 운영기존사진교체·삭제는미실행이다.
