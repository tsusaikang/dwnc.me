# 본문 기준 표 자체의 위치 정렬

- 요구사항: `DWNC-CORE-028`, `PLAN-09`.
- 상태: 최종 소스 `00dfa76`의 구현·관련 회귀·로컬 브라우저·독립 검토·최종 빌드와 공개·관리자 Git 자동 배포·운영 메뉴 읽기 확인 완료.

## 요청과 범위

사용자는 셀 안 글자의 정렬은 되지만 표 전체를 본문 기준 왼쪽·가운데·오른쪽으로 배치할 수 없다고 지적했다. 직전 표 기능 질문은 기존 지원 범위 설명과 관련 시험 확인만 했으며 표 기능 업데이트는 없었다.

`더보기 → 표 편집`에서 셀 정렬과 구분되는 `표 위치` 좌·중·우 조절을 제공한다. 대상 표의 위치만 바꾸고 셀 정렬·내용·행/열·병합·너비·서식과 주변 본문을 보존한다. 기존 표 생성·행/열·셀 편집 등 지원 기능은 유지하며 표 전체 선택·삭제 전용 UI는 이번 범위에 추가하지 않는다.

기존 실행 취소/다시 실행·작업본 자동저장·revision 충돌 처리·명시적 공개 반영 분리와 함께 동작해야 한다. 저장/재열기·미리보기·공개 표시에서도 표 위치가 유지돼야 한다. 실제 운영 글·작업본·사진·공개 상태를 시험 수정하지 않는다.

## 역할과 확인 범위

구현과 독립적인 기존 동작 점검은 하위 에이전트가 맡고 메인은 사용자 세션에 묶인 브라우저·통합·Git 배포·운영 읽기 확인을 맡는다. 직전 로그인 진입 완료를 이번 표 기능 확인으로 대신하지 않는다.

현재 위치와 완료조건은 [공식 상태](../../PROJECT_STATE.md) 및 [현재 요구사항](../REQUIREMENTS.md)을 따른다. 아래 공개 표시 시험도 실제 운영 글이 아닌 로컬 합성 자료다.

## 로컬 브라우저 확인

새 합성 글의 표(머리 셀 2개·일반 셀 2개)에 서로 다른 오른쪽·가운데 셀 정렬을 두고 표 위치를 바꿨다. 본문 폭 860px·표 폭 104.25px에서 표 왼쪽 좌표가 왼쪽 배치 210px, 가운데 587.875px, 오른쪽 965.75px로 바뀌었으며 셀 안 정렬은 유지됐다. 각 선택 상태도 확인했다.

실행 취소로 왼쪽, 다시 실행으로 가운데 위치가 복원됐다. 저장 후 목록에서 재열어도 위치 표시·여백 스타일·기존 셀 정렬이 유지됐다. PC 미리보기 본문 폭 852px와 모바일 미리보기 폭 350px에서 가운데 배치를 확인했다.

같은 합성 글을 로컬에서 공개 반영한 뒤 실제 공개 Worker 경로 `4324/posts/597`를 열었다. 본문 폭 720px에서 본문 중심과 표 중심이 모두 720.5px였고 셀 정렬도 유지됨을 화면으로 확인했다. 운영 게시물 입력·저장·공개 전환은 하지 않았다.

## 독립 검토·최종 시험

관련 회귀와 최초 최종 소스 빌드를 통과했다. 독립 변경 검토에서 기존 표의 class가 제거되는 회귀를 막기 위해 `native-content` 변경을 원복했다. 기존 표 class와 위치 표시를 함께 보존하는 저장 정리·native/legacy 저장·재열기 회귀를 통과했고 수정 후 최종 빌드도 종료 코드 0이었다. 최종 빌드 기록은 `/private/tmp/dwnc-table-position-final-build.log`이며 오류·경고 0·기존 힌트 22개다. 공개 파일 목록은 변경하지 않았다.

최종 기능 변경은 편집기 확장 도구, 가져온 콘텐츠 표시 스타일, 표 위치 전용 시험과 시험 명령 연결의 4개 파일이다. 위치 UI·CSS는 앞선 로컬 브라우저 확인과 같으며 저장 정리 경로의 기존 class 보존은 후속 회귀로 확인했다. 기능 소스 `00dfa76`을 커밋·원격 푸시한 뒤 아래 양쪽 배포와 운영 확인을 마쳤다.

## 최종 배포·운영 메뉴 확인

동일 소스 `00dfa76`의 공개 CI 빌드 `d746ccc2`와 관리자 CI 빌드 `0a4f423b`가 모두 Success임을 확인했다. 활성 버전은 공개 `2b8baeb7`, 관리자 `361a0558`이다.

별도 운영 관리자 탭에서 현재 글의 표 셀에 커서를 놓고 `더보기 → 표 편집`을 열었다. `표 위치` 왼쪽·가운데·오른쪽 선택과 왼쪽 선택 상태, 안내문이 실제 표시되는 것을 확인했다. 위치 버튼을 누르거나 본문을 입력·저장·공개하지 않았다. 메뉴를 닫은 뒤 저장 완료 상태와 마지막 저장시각이 그대로임을 확인하고 별도 확인 탭을 닫았으며 사용자 기존 탭은 유지했다. 운영 글의 제목·본문 등 고유 내용은 기록하지 않는다.

운영 공개 본문에서도 기존 표가 표시되고 새 표 위치 표시 규칙(`table.dwnc-table-positioned`, `width:fit-content`)이 전달되는 것을 읽기 확인했다. 본문은 변경하지 않았다.

표 위치를 바꾸는 실제 조작·실행 취소·저장/재열기·미리보기·공개 Worker 표시는 위 로컬 합성 글의 검증이다. 운영에서는 새 메뉴·선택 상태·안내 반영과 기존 저장 상태 보존을 읽기 확인했으며 실제 운영 표 위치 변경 시험으로 확대하지 않는다. `CORE-028`의 안정 ID·완료조건을 그대로 [완료 원장](../REQUIREMENTS_ARCHIVE.md)에 옮겼고 현재 미해결·다음 행동은 [공식 상태](../../PROJECT_STATE.md)를 따른다.
