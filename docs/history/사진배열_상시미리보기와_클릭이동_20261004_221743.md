# 사진 배열 상시 미리보기와 클릭 이동

작성: 2026-10-04 KST. `DWNC-CORE-040`, `PLAN-09`.

## 요청과 변경

사용자는 별도 `전체 사진 순서` 버튼으로 창을 열고 목표 번호를 입력하는 흐름 대신, 사진 도구가 떠 있을 때 실제 배열도 함께 보고 원하는 위치를 클릭하도록 요청했다. CORE-038/039의 기존 완료 기록은 당시 동작으로 보존하고 이번 후속 요구로 UI를 교체한다.

사진 선택 시 `사진 위치 옮기기` 패널이 자동 표시된다. 데스크톱은 본문 오른쪽 공간을 확보하고, 좁은 화면은 하단 일부에 표시하며 사진 도구를 그 위에 놓는다. 그룹 사진은 같은 줄, 전체 이미지는 잘리지 않는 축소 사진으로 표시한다. 미리보기 사진 클릭은 옮길 사진 선택, 위치 버튼 클릭은 즉시 이동이다. 같은 줄 안의 위치와 줄 사이 위치, 본문을 사이에 둔 앞 사진 뒤/다음 사진 앞을 구분한다. 숫자 입력·번호 이동·미리보기 열기 버튼은 제거했다.

기존 이동·그룹 분리·사진 설명·주변 본문·한 번 undo/redo와 작업본/공개 분리를 유지한다. 패널은 본문 밖에 있어 저장 내용에 포함되지 않는다. 패널 안의 Cmd/Ctrl+Z와 Escape, 선택·스크롤·포커스, busy/IME·다른 글/삭제된 사진 방어를 연결했다.
