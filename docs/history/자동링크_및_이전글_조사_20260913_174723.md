# 자동 링크와 이전 글 링크 조사

조사일: 2026-09-13 KST. 사용자 요청은 **파악만**이며 편집기·기존 글·작업본을 수정하지 않았다. 현재 상태는 [공식 상태](../../PROJECT_STATE.md), 후속 완료조건은 [요구사항](../REQUIREMENTS.md)의 DWNC-CORE-017을 따른다.

## 결론

- 새 글 `/posts/597`의 Logitech 주소는 운영 본문에서도 링크 없는 div 텍스트다. 자체 편집기에는 일반 URL 입력·붙여넣기의 자동 링크 기능이 없다.
- 보존된 이전 글 596편의 원본과 정규화 본문을 전수 대조했다. 실제 참조로 읽히는 미링크 URL은 10편 12곳이며 모두 보존 원본부터 일반 텍스트였다. 조사한 URL에서 이전 과정의 anchor→일반텍스트 손실은 발견하지 못했다.
- 기존 편집기와 보존 원본만으로는 사용자가 과거에 링크 해제를 선택했는지 확정할 수 없다. 원본부터 텍스트인 주소를 모두 이관 결함으로 간주하거나 일괄 수정하지 않는다.

## 편집기 조사

- `src/lib/admin-formatting.ts`: 수동 링크 적용/해제만 있고, 일반 주소 입력·붙여넣기에 URL 감지 처리가 없다. HTML·이미지 붙여넣기는 별도 처리한다.
- `src/lib/admin-ui.ts`: 본문 innerHTML을 저장한다. `src/lib/native-content.ts`: 정상 http/https anchor는 보존하지만 일반 텍스트를 자동 변환하지 않는다. Markdown에서도 명시적 링크 문법만 처리한다.
- `src/lib/native-public-worker.ts`: 저장된 HTML을 표시한다. 운영 새 글의 `.prose`에는 anchor가 없고 해당 주소가 div 텍스트로 존재함을 읽기 전용 DOM으로 확인했다.
- 기존 메모리 DB fixture와 순수함수에 일반 URL 텍스트·정상 anchor·anchor를 없앤 텍스트의 세 합성 HTML을 각각 넣어 저장·재열기·공개본 반환에서 보존함을 확인했다. 저장 과정의 정상 링크 제거는 재현되지 않았다. 운영 편집기 입력 시험은 하지 않았다.
- 링크 해제는 `execCommand('unlink')`이며 영속적인 의도 표식이 없다. `admin-editor-history.ts`의 실행 취소 내역은 브라우저 메모리에만 있다. 향후 자동 링크가 해제 의도를 덮어쓰지 않으려면 저장·재열기까지 유지되는 규칙이 필요하다.

| 네이버 비공개 | 247 | 5편 5곳 |

596편 모두 보존 원본과 정규화 본문을 읽었으며 누락·분석 오류는 없었다. 네이버는 진단용 전체 페이지 대신 검증된 canonical article HTML을 사용했다. 본문 텍스트와 anchor 조상을 비교하고 이미지 src·script·metadata·페이지 UI를 제외했다. 공개 349편의 기존 로컬 렌더 결과와 현재 `sanitizeLegacyHtml`에서도 조사 대상 URL의 링크 탈락은 발견하지 못했다.

공개 후보는 `/posts/435`, `/posts/482`, `/posts/527`, `/posts/556`(3곳), `/posts/570`이다. 출처·참고 주소 문맥이다. 12곳은 http(s) 또는 www 형식을 대상으로 문맥 분류한 결과이며 모든 도메인 문자열의 총수가 아니다.

- 공개 기술 설명 글 `/posts/544`의 `www.example.com` 예시 4곳과 코드 내부 예시 1곳은 보완 후보에서 제외했다.
- 프로토콜·www 없는 도메인 문구는 공개 5편 22곳·비공개 1곳을 별도 분류했다. 서버명·기술 예시·명령 설명이 대부분이며 `/posts/318` 사진 캡션의 `Fina.org` 2곳도 포함한다. 자동 링크 대상으로 일괄 합산하지 않는다.
- 공개 네이버 원본 URL 1곳의 제거는 비공개 글 링크를 안내 문구로 대체한 기존 개인정보 보호 처리였다.
- 네이버 원본의 `linkUse=false` 3,056개는 모두 글자 없는 이미지 anchor 설정이다. 텍스트 링크 해제 의도의 증거가 아니다.
- 보관 원본은 캡처 당시 상태다. 최초 작성 당시 자동 링크 동작이나 캡처 이전의 편집 의도는 소급 확정할 수 없다. 외부 주소의 접속 가능 여부는 조사하지 않았다.

## 운영 확인과 한계

- 운영 공개 후보 5편을 `?preview=1`·curl User-Agent로 읽었으며 모두 HTTP 200이었다. 후보 URL 7곳은 현재도 일반 텍스트이고, 이 5편에서 로컬 렌더의 기존 텍스트 링크가 운영에서 추가로 사라진 사례는 없었다. 외부 링크·미디어는 요청하지 않았다.

- 메인이 내장 브라우저에서 프로젝트 계정 확인값을 대조한 뒤 D1 콘솔의 SELECT 집계만 실행했다. 운영 이전 글 596편·입력 완료 596편, revision이 증가한 저장본 1편, 이전 글 작업본 1편이며 작업본 본문과 저장본 본문이 다른 글은 0편이다.
- revision은 본문 일치 확인값이 아니다. 공개 초기 입력은 당시 dist의 본문을 정제한 결과이고 비공개 입력은 미디어 주소 치환·iframe 링크 대체·정제를 거친다. 위 집계는 운영 본문 전체와 보관 원본의 직접 대조를 대신하지 않는다.
- 운영 본문·작업본 596편 전체를 이번에 다운로드하여 대조하지 않았다. 기존 Wrangler 로컬 인증이 없어 CLI 조회는 실행되지 않았으며 별도 인증 발급 없이 로그인된 내장 대시보드에서 집계했다.
- 운영 글 확인은 `?preview=1`을 사용했다. 기존 집계 제외 조건을 유지했으며 조회수 초기화·정책 변경은 하지 않았다.

## 후속 제안과 승인 범위

현재는 조사만 완료했다. 구현 지시를 받으면 새 입력·붙여넣기의 완성된 URL 자동 링크, 기존 anchor·코드·문장부호·한글 입력 처리, 명시적 링크 해제의 저장 후 유지부터 보완한다. 기존 글은 보완 후보를 운영 최신 본문·작업본과 대조하고 확정한 범위만 수정한다. 원본 캡처·글 주소·공개 상태·미디어·다른 편집 내용은 유지한다.

하위 에이전트가 편집기/이전 원본 조사를 맡고 메인이 운영 브라우저·집계·통합·공식 기록을 맡았다. 비공개 실제 제목·주소·본문은 이 문서에 싣지 않는다. 상세 집계는 기존 Git 제외 영역 `migration/private/link-audit-20260913.json`, `migration/private/link-audit-domains-20260913.json`(0600)에만 보관한다. 공개 저장소에는 이 요약과 후속 요구사항만 동기화한다.
