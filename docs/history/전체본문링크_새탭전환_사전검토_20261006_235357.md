# 전체 본문 링크의 새 탭 전환 사전 검토

2026-10-06 KST · `DWNC-CORE-049` · `PLAN-09` · 검토만 완료.

## 결론

현재 자료에서는 내부 글·외부 사이트·링크 카드·링크가 있는 사진을 새 탭으로 여는 데 중대한 충돌을 발견하지 않았다. 글 DB를 일괄 수정하지 않고 읽기 화면의 최종 본문 링크에 새 탭 속성을 적용하는 방법을 권한다. 본문 내용·작업본·revision·공개 범위를 보존할 수 있다.

사용자는 변경 전에 검토까지만 요청했다. 이번에는 새 탭 전환 코드·기술 계약·실제 콘텐츠·작업본·공개 상태를 변경하지 않았다. 병행한 `CORE-048` 주소 끝 하이퍼링크 복원 배포와 별개다.

## 최신 전수 조사 범위

## 적용 방식과 보존 조건

- 공개 본문 안의 HTTP(S) 링크를 새 탭으로 요청한다. 내부 글·외부 사이트·카드·링크가 있는 사진에 같은 규칙을 적용한다. 사이트 메뉴·카테고리·태그·이전/다음 글·관리자 탐색은 본문 링크 요청과 구분해 유지한다.
- 동적 글의 카드/이관 표시 보정 뒤, 정적 fallback 본문, 관리자 미리보기의 최종 표시 단계에 같은 정책이 필요하다. 실제 편집 본문을 열거나 저장할 때 원문을 일괄 바꾸지 않는다.
- 기존 내부 링크를 같은 탭으로 여는 계약이 있으므로 적용 승인이 나면 최종 본문 표시 정책과 계약을 함께 갱신해야 한다. URL 정규화·연결 주소·글 제목·사진 파일은 유지한다.
- `target="_blank"`와 `noopener`를 적용하고 기존 `rel`은 보존한다. 새로 모든 링크에 `noreferrer`를 강제하지 않는다. 이는 새 탭과 별도로 출처 정보를 없애는 변경이기 때문이다. [HTML 표준](https://html.spec.whatwg.org/multipage/links.html#link-type-noreferrer).
- 공개 외부 주소의 `#위치`156개는 주소 일부로 그대로 유지한다. 현재948본문에는 `#` 단독 이동·메일·전화·download 속성·빈 주소·위험한 scheme이 없다. 향후 같은 글 안 위치 이동·메일/전화 실행·명시적 다운로드는 의미를 유지하는 예외를 두는 편이 적절하다.
- 링크 없는 사진의 기존 원본 크기 팝업은 유지한다. 사진에 링크가 있으면 그 링크 목적지가 새 탭으로 열린다. 새 탭/새 창의 최종 선택과 파일 다운로드 처리는 브라우저·대상 서버가 결정하는 부분이다.

## 검토 근거와 한계

전수 분석과 적용 방식 조사를 한 에이전트에, 집계·정책의 독립 검토를 다른 에이전트에 위임했다. 메인은 로그인 운영 데이터 SELECT·전체 결과 로컬 보관·범위 확인·통합·공식 기록을 맡았다. 브라우저와 최신 운영 원문에 접근해야 하는 동작만 메인이 수행했다.

현재 공개359본문에 기존 카드/이관 표시 함수를 로컬 메모리에서 읽기 전용으로 적용한 제한된 모의 검토에서는 저장 링크431개에 자동 카드 링크17개가 더해져448개가 됐으며 변경 대상289개/64글은 같았다. 외부 메타데이터 조회는 금지했고 정본주소 lookup은 identity로 제한했다. 이는 모든 운영 공개 화면을 실제 클릭하거나 전체 URL의 응답 정상 여부를 시험한 결과가 아니다.

모의 DOM에서 제안한 target/rel만 적용했을 때 주소·표시 문자·다른 DOM 구조·fragment 변화는0이었다. 실제 새 탭 클릭 시험·구현·배포는 수행하지 않았다. 적용 승인 후 공통 규칙 구현·관련 회귀·합성 클릭·최종 빌드·배포와 운영 읽기를 진행할 수 있다.

운영 본문·개별 사유/주소를 포함한 입력과 상세 분석은 로컬 `/private/tmp`에만 보관하고 Git에는 넣지 않았다. 원문 입력 `dwnc-live-link-bodies_20261006_194500.json`, 전수 집계 `dwnc-link-review-summary_20261006_194700.json`, 제한된 표현 모의 검토 `dwnc-link-presentation-review_20261006_195000.json`는 파일명의 시각보다 내부 `queriedAt`을 조회 시각의 정본으로 사용한다.
