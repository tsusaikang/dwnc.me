# 사진 설명 기본 가운데 정렬

- 요구사항: `DWNC-CORE-030`, `PLAN-09`.
- 상태: 2026-09-23 관련 회귀·로컬 확인·최종 빌드·양쪽 Git 배포·운영 읽기 확인 완료. 실제 콘텐츠 쓰기·공개 반영은 0이다.

## 요청과 범위

사진 설명의 기본 정렬을 본문에서 분리해 가운데로 표시한다. 사진 자체의 배치도 기본 설명 정렬을 바꾸지 않으며 기존에 명시적으로 지정한 설명 정렬은 보존한다. 캡션 내용·내부 서식·원본 사진·사진 그룹·주변 문단을 보존하고 저장 콘텐츠를 일괄 재작성하지 않는다.

편집기·미리보기·공개 화면에 같은 규칙을 적용한다. 관련 회귀·로컬 브라우저·최종 소스 빌드·기존 Git 자동 배포·운영 읽기 확인으로 완료를 판단하며 실제 글이나 작업본 쓰기·공개 반영은 하지 않는다. 앞선 #599 작업본 정리는 별도 완료 이력이며 후속 사용자 반영 상태는 아래 최신 운영 읽기로 구분한다.

## 역할과 다음 확인

코드 담당은 표현 규칙과 관련 회귀를 보완하고 메인은 이번 요청을 위한 최신 운영 사례 읽기·사용자 세션에 묶인 브라우저 확인·Git 배포를 맡는다. 문서 담당은 전달된 결과의 실제 확인 범위를 기록한다. 기존 운영 관측을 이번 요청의 새 조회 결과로 대신하지 않는다.

완료조건과 근거는 [완료 원장](../REQUIREMENTS_ARCHIVE.md), 다음 행동과 승인 경계는 [공식 상태](../../PROJECT_STATE.md)를 따른다. 운영 고유 제목·본문·사진 경로는 이 기록에 넣지 않는다.

## 최신 운영 읽기와 이전 작업본 상태

메인이 별도 운영 관리자 탭에서 #599를 새로 읽었다. 마지막 저장은 2026-09-23 00:30:09 KST이고 작업본과 공개 내용이 같았다. 설명에 `text-align:center`가 명시돼 있으며 계산된 정렬은 설명 center·본문 start·사진 start였다. 앞선 `CORE-029` 마감 당시 미공개 작업본 상태는 이후 사용자 반영으로 해소된 것으로 볼 수 있다. 이번 에이전트가 공개한 것은 아니며 이번 읽기 중 내용 쓰기·공개 반영은 0이다.

## 로컬 확인 결과

원인은 편집기에 공통 설명 정렬 규칙이 없고 공개 표현의 뒤쪽 전역 규칙이 왼쪽 정렬로 덮는 경로였다. 로컬 편집기에서 명시적 style이 없는 figcaption은 계산된 가운데 정렬과 도구막대 가운데 선택 상태를 보였다. 설명을 직접 오른쪽 정렬해도 본문은 start를 유지했다.

합성 HTML의 본문 문단·사진 배치를 오른쪽으로 둔 조건에서 기본 figcaption은 center, 명시적 figcaption은 left, 네이버 `se-caption`의 기본 문단은 center, `se_mediaCaption`의 명시적 문단은 right였다. 편집기·미리보기·저장 후 다시 열기와 로컬 합성 공개 페이지(`/posts/1`, 로컬 공개 Worker)에서 모두 같은 center/left/center/right 결과를 확인했다. 실제 운영 글을 바꾸거나 공개해 시험하지 않았다.

독립 검토에서 진행을 막는 문제는 없었다. 이 확인은 로컬 표현 결과이며 최종 소스 빌드·양쪽 Git 배포·운영 새 규칙 확인까지 완료했다고 판정하지 않는다.

## 최종 소스 확인과 배포 진행

관련 회귀와 최종 소스 빌드를 통과했다(exit 0, Astro 오류·경고 0, 비공개 자료 누출 0). 공개 요청 표면 1,425개에서 CSS 해시 경로 한 개만 교체됐다. 표현은 `src/lib/imported-presentation.ts`·`src/styles/global.css`, 편집 정렬 상태는 `src/lib/admin-formatting.ts`에서 보완했으며 관련 검사 `scripts/test-caption-alignment.mjs`와 실행 항목·공개 요청 표면 기준을 갱신했다.

기본 가운데는 명시적 사진 설명 정렬이 없는 경우에만 적용하고 기존 명시적 정렬은 유지한다. 본문 문단·사진 배치·저장된 내용의 변경과 구분하는 표현 보완이다. 메인이 기능 소스 `8fb004a`를 커밋·푸시해 양쪽 자동 배포가 시작됐다. 이 시점에는 배포 성공과 운영 반영을 아직 확인하지 않았으며 실제 콘텐츠 쓰기·공개 반영은 0이다.

## 운영 반영과 완료

기능 소스 `8fb004a`의 공개·관리자 Cloudflare 자동 배포가 모두 Success임을 확인했다. 운영 관리자 새로고침에서 기본 설명 정렬 CSS와 도구막대 `captionFormatAlignment` 처리가 반영됐고 #599의 기존 명시적 `text-align:center`와 계산된 가운데 정렬이 유지됐다.

운영 공개 #600에서 `:is(.prose,.html-editor) :where(figcaption,.se-caption,.se_mediaCaption){text-align:center}` 공통 스타일시트가 실제 로딩됨을 확인했다. 로컬에서 확인한 기본값·명시적 정렬의 조작 결과와 운영 코드·기존 정렬 읽기를 구분한다. 운영 콘텐츠는 쓰거나 공개하지 않았다.

요구사항 `DWNC-CORE-030`의 완료조건을 보존해 완료 원장으로 이동했다. 별도 사진 저장·조회 비용 설명은 읽기 전용 참고이며 이번 정렬 기능이나 요금제 변경으로 확대하지 않는다.
