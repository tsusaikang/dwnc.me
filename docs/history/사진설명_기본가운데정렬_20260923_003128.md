# 사진 설명 기본 가운데 정렬

- 요구사항: `DWNC-CORE-030`, `PLAN-09`.
- 상태: 2026-09-23 요청 등록·구현 검토 진행. 이번 운영 사례 읽기와 로컬 동작·독립 검토를 완료했고 최종 소스 빌드·양쪽 배포·운영 새 규칙 확인은 대기 중이다.

## 요청과 범위

사진 설명의 기본 정렬을 본문에서 분리해 가운데로 표시한다. 사진 자체의 배치도 기본 설명 정렬을 바꾸지 않으며 기존에 명시적으로 지정한 설명 정렬은 보존한다. 캡션 내용·내부 서식·원본 사진·사진 그룹·주변 문단을 보존하고 저장 콘텐츠를 일괄 재작성하지 않는다.

편집기·미리보기·공개 화면에 같은 규칙을 적용한다. 관련 회귀·로컬 브라우저·최종 소스 빌드·기존 Git 자동 배포·운영 읽기 확인으로 완료를 판단하며 실제 글이나 작업본 쓰기·공개 반영은 하지 않는다. 앞선 #599 작업본 정리와 공개 여부는 별도 기존 상태로 유지한다.

## 역할과 다음 확인

코드 담당은 표현 규칙과 관련 회귀를 보완하고 메인은 이번 요청을 위한 최신 운영 사례 읽기·사용자 세션에 묶인 브라우저 확인·Git 배포를 맡는다. 문서 담당은 전달된 결과의 실제 확인 범위를 기록한다. 기존 운영 관측을 이번 요청의 새 조회 결과로 대신하지 않는다.

현재 완료조건은 [요구사항](../REQUIREMENTS.md), 다음 행동과 승인 경계는 [공식 상태](../../PROJECT_STATE.md)를 따른다. 운영 고유 제목·본문·사진 경로는 이 기록에 넣지 않는다.

## 최신 운영 읽기와 이전 작업본 상태

메인이 별도 운영 관리자 탭에서 #599를 새로 읽었다. 마지막 저장은 2026-09-23 00:30:09 KST이고 작업본과 공개 내용이 같았다. 설명에 `text-align:center`가 명시돼 있으며 계산된 정렬은 설명 center·본문 start·사진 start였다. 앞선 `CORE-029` 마감 당시 미공개 작업본 상태는 이후 사용자 반영으로 해소된 것으로 볼 수 있다. 이번 에이전트가 공개한 것은 아니며 이번 읽기 중 내용 쓰기·공개 반영은 0이다.

## 로컬 확인 결과

원인은 편집기에 공통 설명 정렬 규칙이 없고 공개 표현의 뒤쪽 전역 규칙이 왼쪽 정렬로 덮는 경로였다. 로컬 편집기에서 명시적 style이 없는 figcaption은 계산된 가운데 정렬과 도구막대 가운데 선택 상태를 보였다. 설명을 직접 오른쪽 정렬해도 본문은 start를 유지했다.

합성 HTML의 본문 문단·사진 배치를 오른쪽으로 둔 조건에서 기본 figcaption은 center, 명시적 figcaption은 left, 네이버 `se-caption`의 기본 문단은 center, `se_mediaCaption`의 명시적 문단은 right였다. 편집기·미리보기·저장 후 다시 열기와 로컬 합성 공개 페이지(`/posts/1`, 로컬 공개 Worker)에서 모두 같은 center/left/center/right 결과를 확인했다. 실제 운영 글을 바꾸거나 공개해 시험하지 않았다.

독립 검토에서 진행을 막는 문제는 없었다. 이 확인은 로컬 표현 결과이며 최종 소스 빌드·양쪽 Git 배포·운영 새 규칙 확인까지 완료했다고 판정하지 않는다.
