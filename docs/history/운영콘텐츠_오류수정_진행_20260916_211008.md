# CORE-021 오류 수정 진행과 승인 검토 중단

2026-09-16. 재조사 뒤 사용자가 “문제되는 부분은 끝까지 확인해야지? 필요하다면 수정하고”라고 추가 지시했다. 메인은 이를 확인된 오류의 필요한 수정 승인으로 해석해 정상 관리자 UI로 적용을 시작했다. 이후 자동 승인 검토가 최초 수정·공개 금지 지시와의 관계 및 대량 공개 반영 범위를 불명확하다고 판단해 중단했다. 차단을 우회하지 않았으며 이후 콘텐츠 쓰기와 Cloudflare 접근을 하지 않았다.

## 실제 반영된 결과

- 대표이미지27건: 공개16건(기존깨짐14·T로고2)과 비공개빈11건의 대표 지정 해제. 최신 본문에 대체 실사진이 없어 임의사진을 고르지 않았다. 원본파일은 삭제하지 않았고 기존 공개상태를 유지했다.
- 공개요약29편: 옛 네이버 편집 메뉴를 제거하고 현재본문의 실제문장으로 수정, 자동저장과 명시적 공개반영 완료 안내를 확인했다.
- 공개 API 전체350편의21:08경 결과에서 공개대표16건 해제와 요약29편 새값이 모두 일치했다.
- 첫대표8편은 D1반영본까지 읽어 본문HTML·공개상태 불변을 확인했다. body_text가 달라진6편은 &,<,>의 엔티티 변환뿐이며 디코딩뒤 기존문장과 같았다.
- 전체27대표·29요약의 최종D1 대조는 이후 출처접근 차단으로 완료하지 못했다. 화면완료안내와 공개API 확인을 전체DB확인으로 과장하지 않는다.

## 준비됐지만 적용하지 않은 것

- 공개요약: 전체144편 중 남은115편. 기존공개상태를 유지한 수정·공개반영 대기.
- 비공개요약:248편 중 명백편집/영상메뉴혼입178편의 최소수정안. 정상70편은 유지하며 적용0건이다. 작성문구가 충분하지 않은 경우 현재제목을 사용해 내용을 창작하지 않는다.
- 카드:285→273 현재제목 일치,331 Google공식소개 주소,78 동일FINA PDF의 SwimSwam보관본 표시,318 Instagram접근불가안내의 최소HTML안.361 동일원문은 찾지못해 원링크보존+서비스종료안내 방안이며 대체기사를 같은원문으로 취급하지 않는다.
- 위키는 정확문서/공개보관본 검색에도 확인되지 않았다. 보관본존재확인은 도구제한으로 단정불가다. 카페는 네이버로그인이 필요해 사용자의 직접로그인을 요청했다. 원문삭제나 영구장애로 단정하지 않는다.
- 편집화면: 옛네이버영상의 고정높이/메뉴표시가 글정보영역을 덮는 원인 확인. 원본HTML을 바꾸지 않고 재생원본 없는 레거시플레이어만 안내로 보여주는 CSS를 준비했다.27편36개 현재플레이어에 해당하며 일반동영상/실제source/사진/기존안내는 제외한다. 아직운영배포하지 않았다.

## 검증

- 편집UI·작업본·비공개런타임·서식회귀와 타입검사 통과. 내장브라우저 합성화면에서 영상앞뒤본문·캡션·안내·글정보/요약 겹침없음 확인. 합성서버 종료.
- native-editor 전체시험의 홈목록0 대7 기대실패는 수정전HEAD를 별도임시경로에 추출해도 동일 재현됐다. 기존시험결함은 수정하지 않았고 신규선택범위회귀는 통과했다.
- 최종소스 전용빌드 통과. 요구사항검사 통과. 코드수정은 admin-ui.ts의 CSS와 관련 기존회귀에 한정한다.
- 최신운영입력·수정안·적용기록·개인별비공개내용·공개API결과·빌드로그는 Git제외 migration/private/core021_fix_20260916/에 있다. 비공개제목/본문/식별값/계정값은 이보고서와Git에 넣지 않는다.

## 실제 중단 이유와 재개 조건

자동 승인 검토의 첫거절은 “최초콘텐츠수정·공개금지와 후속수정지시만으로144편규모공개반영의 명시승인이 불충분하다”는 이유였다. 두번째는 “Cloudflare 대시보드와 이번사이트의 직접관련근거가없고 인증된운영정보접근이 승인되지않았다”는 이유로 최종SELECT읽기를 막았다. 대상계정은 기존프로젝트 확인값과 일치했고 dwnc.me 운영DB를 사용했지만, 거절이후 같은목적의 우회접근을 하지 않았다.

사용자에게 준비된 전체수정안을 보여주고 다음네범위의 명시승인을 요청한 상태다: 공개요약115편 반영,비공개요약178편 비공개유지수정,확인된카드/편집화면수정배포,dwnc.me 기존Cloudflare DB읽기확인. 네이버카페내용확인을위한 직접로그인도 별도로대기중이다. 답변이오기전 추가반영하지 않는다.

## 다음 행동과 보존

1. 명시승인이오면 현재운영반영본·작업본과 적용기록을 대조하고 이미반영한27대표·29요약을 중복적용하지 않는다.
2. 남은115공개요약·승인된비공개요약·카드를 정상UI로 수정하고각각현재공개상태를유지한다. expectedRevision충돌시최신작업본을다시읽고해당수정만적용한다.
3. 허용된운영읽기와실제화면으로결과를검증하고 코드배포도별도활성화확인한다.
4. 승인거절이나사용자추가선택없이 전체수정완료로 처리하지 않는다. 이시점의코드변경은로컬커밋보존대상이며 자동배포를일으키는푸시는명시승인전보류한다.

메인은 사용자세션이필요한운영접근·브라우저수정·통합을맡고 하위에이전트는사진/요약/카드분석과겹침CSS구현을분담했다. 이전초기조사·재조사보고서는수정하지않고보존했다.
