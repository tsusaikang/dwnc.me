# 단독 URL 문단의 링크 카드 — 구현·전수조사 완료 기록

기준 시점: 2026-09-25. `DWNC-CORE-033`. 아래 앞부분은 진행 이력이며, 최종 완료 결과는 마지막 절을 기준으로 한다.

## 결정과 범위

사용자는 직접 입력, 주소 한 줄 붙여넣기, 글 전체 붙여넣기와 기존 글에 동일한 기준을 적용하도록 요청했다. 한 문단 전체가 웹주소 하나인 경우만 카드로 변환한다. 문장 속 주소·여러 주소가 든 문단·명시적으로 링크를 해제한 내용은 유지한다. 기존 카드·코드·목록·인용·표·제목 내부는 자동 카드 대상에서 제외한다. 문단 끝의 빈 줄은 허용하되 같은 문단에 다른 문장이 있으면 제외한다.

기존 글은 DB 원문을 일괄 수정하지 않고 공개 표시와 편집기 초기 표시에서 공통 변환한다. 미공개 작업본을 공개 반영하지 않으며 GET 조회만으로 revision이나 저장 본문을 바꾸지 않는다. 사용자가 이후 편집·저장하면 화면의 카드 표현이 일반 작업본 저장 경로를 따른다.

내부 글은 공개 가능한 목록의 제목·설명·대표 사진을 사용한다. 외부 주소는 제한된 메타데이터 조회로 제목·설명을 가져오며 실패하면 주소·호스트만 표시하는 카드로 남긴다. 외부 사이트 대표 이미지 수집은 지원하지 않는다. 공개 화면도 메타데이터를 항상 확보한다고 보장하지 않으며 실패·조회 예산 초과 시 기본 카드가 표시된다.

## 구현과 검토 근거

- 공통 판별·표시: `src/lib/url-link-cards.ts`. 직접 입력·붙여넣기: `src/lib/admin-autolink.ts`. 관리자 조회·미리보기와 공개 렌더링에서 공통 처리를 사용한다.
- 기존 root 텍스트/링크도 문단 경계에 따라 처리한다. 네이버 기존 카드 안의 중첩 변환을 제외하고, 바뀌는 문단의 `id/style/align/dir/lang`을 유지한다.
- 검토 중 root 텍스트 URL이 다른 후보와 함께 있을 때 사라지는 문제가 발견돼 수정했다. 최종 공통 판별 합성 검사는 root 텍스트·링크, BR, 기존 네이버 카드, 문장·여러 URL 제외, 속성 보존과 재변환 방지를 통과했다.
- 외부 조회는 웹 프로토콜·공개 주소·리디렉션·응답 크기·시간을 제한하고 인증 쿠키를 전달하지 않는다.

## 최신 운영 전수조사: 부분 확인

현재 공개 search-index 355편을 기준으로 HTTP 본문을 조회했다. 85편은 읽기에 성공했고 5편에서 단독 URL 5개를 확인했으며 공통 변환 후 후보 잔여는 0이었다. 270편은 HTTP 503/502 또는 본문 추출 실패로 미확인이다. 대량 재시도는 중단했다. 상세 결과는 Git 제외 `migration/private/core033_20260925/live-public-audit.json`에 있다. 이는 공개 일부에 대한 결과이며 전수조사 완료가 아니다.

Cloudflare 로그인 만료로 사용자 로그인을 기다리고 있다. 이번 요청을 위한 최신 D1 전체 자료를 아직 조회하지 못했으므로 대상 글 수·후보 수를 산출하지 않았다. 과거 이관 덤프와 이전 전수조사 결과를 현재 콘텐츠 대신 사용하지 않는다.

로그인 후 다음 SELECT로 현재 반영본과 별도 작업본을 함께 읽는다. 관리자 일반 글 API는 작업본 우선이므로 반영본 전수조사 입력을 대신할 수 없다.

```sql
SELECT p.*,
  w.post_id AS working_post_id,
  w.body_html AS working_body_html,
  w.body_markdown AS working_body_markdown,
  w.body_format AS working_body_format,
  w.body_text AS working_body_text,
  w.revision AS working_revision,
  w.published_revision,
  w.updated_at AS working_updated_at,
  COALESCE(o.visibility,'public') AS visibility,
  COALESCE(o.kind,'post') AS kind
FROM (
  SELECT id,global_sequence,status,revision,body_html,body_markdown,
    body_format,body_text,updated_at,'native' AS source_kind
  FROM native_posts WHERE status!='tombstone'
  UNION ALL
  SELECT id,global_sequence,status,revision,body_html,body_html AS body_markdown,
    'html' AS body_format,body_text,updated_at,'legacy' AS source_kind
  FROM legacy_posts WHERE import_complete=1 AND status!='tombstone'
) p
LEFT JOIN editor_working_copies w ON w.post_id=p.id
LEFT JOIN content_operations o ON o.post_id=p.id
ORDER BY p.global_sequence,p.id;
```

읽은 자료를 `{source:"live-d1", fetchedAt:"실제 조회 시각", rows:[...]}` 형태로 Git 제외 `migration/private/core033_20260925/`에 보관할 수 있다면 다음 읽기 전용 분석기를 사용한다.

```text
node scripts/audit-standalone-url-cards.mjs migration/private/core033_20260925/live-d1.json migration/private/core033_20260925/audit.json
```

분석기는 공통 판별 함수를 사용하며 신규 초안·반영본·작업본을 구분한다. 누락 본문·중복 ID는 실패 처리하고 후보가 없는 본문도 검사 기록에 포함한다. 상세 URL·본문은 공개 문서나 Git에 기록하지 않는다. 브라우저 조회 자료를 파일로 얻을 수 없는 경우 같은 공통 기준으로 현재 읽은 자료를 검사하되, 파일 사본이 있다고 주장하지 않는다.

최신 조회 후 후보 확인, 배포 확인, 운영 대표 사례 확인이 남아 있다. 공개·비공개·예약·보호 상태 및 미공개 수정은 그대로 유지한다.
