## 작업 중 발견한 HTML 편집 오류와 복원

카드 수정 후 최종 공개 화면 검사에서6편 전체 본문이 기존 첫 요소 안에 중첩된 문제를 발견했다.5편은 표시 본문이 비어 있었다. 수정한 카드 값이 HTML 안에 있다는 이유로 완료 처리하지 않았다. 작성 문장과 미디어는 남아 있었지만 본문 구조가 잘못됐음을 분리해 기록했다.

원인은 HTML 전체 편집에도 일반 서식 삽입 명령을 사용한 것이었다. 서버가 정리한 HTML로 편집기 루트의 자식 전체를 정확히 교체하고, 기존 실행 취소·다시 실행에 등록하도록 보완했다. 합성 화면에서 이전 중첩 재현·새 단일 구조·실행 취소·다시 실행을 확인한 뒤 기존 Git 자동 배포로 반영했다.

영향받은6편은 복원 직전 현재 원격 본문이 알려진 반영본과 같은지 확인했다. 중첩 내용을 추정해 추출하지 않고, 처음 검증한 원문에 승인된 카드 변경만 적용한 목표로 복원했다. 공개 반영 전에6개 초안의 DOM 구조·작성 텍스트·모든 미디어 속성을 대조했고, 반영 후 내장 브라우저에서6편 모두 단일 본문·실제 텍스트 표시·카드·보존 링크·안내가 맞는 것을 확인했다. 실패 시점 자료도 보존했다.

## 승인·보존·산출물
