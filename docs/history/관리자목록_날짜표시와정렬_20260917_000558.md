- 최종 기능 소스: `c092833`
- 상태: 2026-09-17 KST 운영 반영·실제 관리자 확인 완료.

## 원인과 변경

기존 목록은 작업본 우선 수정일 하나만 이름 없이 표시했고 수정 최신순이었다. CORE-021 콘텐츠 수정으로 해당 글의 수정일이9월16일로 갱신되어 같은 날 작성한 것처럼 보였다. 이번 운영 조회에서 공개285의 생성일은2016년, 공개411은2019년으로 보존되어 있었다.

생성일·수정일을 각각 라벨과 분 단위 시각으로 표시한다. 이관 글의 생성일은 원래 글 발행일이며 자체 글은 첫 초안 생성 시각이다. 수정일에는 작업본 저장도 포함된다. 화면에 이 의미를 안내하며 기존 사이트 시간대를 따른다. 누락·빈 값·유효하지 않은 날짜는 대시로 표시한다.

생성일 최신순·오래된순, 수정일 최신순·오래된순 네 개만 제공하고 기본 수정일 최신순을 유지한다. 전체 목록을 날짜순으로 정렬한 뒤 필터와 페이지를 적용하며 정렬 변경 시 첫 페이지로 돌아간다. 같은 시각의 시간대 표기를 정규화해 비교하고 동률은 기존 번호·ID 기준으로 안정화한다.

기존 글·작업본·생성일·수정일·발행일·공개 상태·본문을 쓰는 코드는 변경하지 않았다. 관리자 조회와 표시만 보완하며 운영에서 콘텐츠 저장이나 시험 글 생성은 하지 않는다.
