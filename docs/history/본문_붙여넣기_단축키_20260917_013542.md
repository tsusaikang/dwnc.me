# 본문 서식 포함·제외 붙여넣기

- 요구사항: DWNC-CORE-024
- 사용자 결정: 일반 관례 유지. Cmd+V 서식 포함, Shift+Cmd+V 무서식. Ctrl+Shift+V와 Mac Option+Shift+Cmd+V 호환.
- 상태: 구현·관련 회귀·소스 빌드 완료, 합성 브라우저 확인 중.

## 변경과 범위

기존 일반 붙여넣기는 유지한다. 무서식 단축키 의도일 때만 HTML 원문 자동 변환과 사진 업로드를 건너뛰고 브라우저 기본 문자열 삽입을 따른다. 텍스트 없는 사진만의 무서식 붙여넣기는 삽입하지 않는다. 무서식 의도는 한 번만 소비하고 키 해제·다른 키·포커스 이탈·시간 만료·글 변경 시 초기화한다. 일반/메뉴 붙여넣기의 HTML·사진 처리와 기존 자동링크·실행 취소·저장 흐름은 유지한다.

판단은 현재 기능 코드와 이번 운영 관리자 화면을 기준으로 했다. 운영 글이나 작업본을 시험 입력·저장·공개하지 않는다. 운영 원문·브라우저 기록은 Git 제외 migration/private/core024_20260917/에 둔다. 구현·독립 검토는 하위 에이전트, 사용자 세션에 묶인 브라우저·배포·통합·공식 기록은 메인이 맡는다.

## 브라우저 검증 한계

내장 브라우저 자동화의 Meta+Shift+V 및 native super+shift+v는 실제 keydown 없이 trusted:false의 paste 이벤트와 text/plain만 전달했다. 클립보드에 text/html을 함께 넣어도 동일했다. 반면 Meta+A는 실제 keydown/keyup이 기록됐다. 이 때문에 자동화 단축키 실행만으로 제품의 실제 물리 키보드 동작을 검증할 수 없다. 임시 합성 진단으로 이를 확인했으며 진단은 제품 코드에 넣지 않는다.

기존 fixture의 합성 이벤트와 브라우저 기본 입력 대용 동작으로 두 경로를 확인하고, 실제 물리 키보드 시험과 구분한다. 도구가 단축키를 일반 paste로 치환한 결과를 제품 결함이나 무서식 성공으로 오판하지 않는다.
