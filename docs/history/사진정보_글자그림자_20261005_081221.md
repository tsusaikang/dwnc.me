# 사진 정보의 배경 제거와 짙은 글자 그림자

## 요청·완료조건·범위

2026-10-05 사용자 첨부에서 밝은 줄무늬 사진 위 정보가 잘 읽히지 않는다고 지적했다. 반투명 배경+흰 글씨 대신 배경 없이 흰 글씨 자체에 훨씬 어두운 그림자를 넣도록 요청했다. 기존 CORE-041의 표시 후속으로 처리한다. `a5b2ba3`·원격 main·미커밋 없음에서 시작했다.

공개·편집의 요약/상세 모두 투명 배경, 배경 흐림 제거, 같은 짙은 그림자를 적용한다. 배치·확장폭/높이·hover/클릭/키보드 닫기·선택·본문·저장을 유지한다. 관련 기존 검사·최종 소스 빌드·기존 Git 자동배포·양쪽 운영 화면 읽기까지 완료한다. 실제 글·작업본·사진 쓰기, 공개 전환·권한·DNS 변경은 없다.

## 구현·검토·조회

하위 `photo_text_shadow`가 공개 `src/styles/photo-info.css`와 편집 `src/lib/admin-image-direct.ts`의 CSS, 기존 검사2개를 수정했다. `review_shadow`가 독립 읽기 검토했고 실제 오류를 발견하지 못했다. 메인은 통합·브라우저·빌드·문서·Git을 맡았다. 사용자 세션의 자체 브라우저는 메인에 연결돼 있어 메인이 요청된 표시 확인만 직접 수행했다.

- 기존 요약14%·상세22% 검정 배경과 blur8px를 제거했다. 흰 글씨의 사방1px/blur1px 검정95% 네 겹과 아래2px/blur3px 검정90% 한 겹을 적용했다. 공개/편집의 요약·상세·닫기 글씨가 동일하게 상속한다. 편집 hover 배경 우선순위를 유지했다.
- 기존 공개 사진 정보·직접 사진 편집 검사는 통과했다. 소스 변경은 표시 CSS와 그 기존 검사 기대값/표현에 한정하며, 신규 동작·검사 체계를 추가하지 않았다.
- 이번 최신 공개 #600은9사진·총8.26MB, 편집 #605는4사진·공개와 같은 작업본·마지막 저장2026-09-30 21:24:44 KST로 읽었다. 공개 사진3은 첨부와 같은 해상도1928×2560·579,404바이트·Display P3·해당 ICC프로필·HDR 메타데이터를 현재 API로 확인했다. 오래된 이관 덤프를 입력으로 쓰지 않았다. 조회 이후 사용자 수정 가능성은 유지한다.

## 확인과 전달 상태

첫 source build는 변경된 CSS파일명으로 공개 요청목록 drift에서 멈췄다. 새 빌드 산출물의 목록을 재생성한 뒤 최종 source build와 전체 편집기 회귀를 직렬 실행해 모두 통과했다. Astro 오류0·공개1435경로·비공개 누출0이며 요구사항 검사와 변경형식 검사도 통과했다. 새 공개 surface는1435경로, SHA256 `8a3c4c4ae3f579713f6e5a90b24d15728a1020161ca2adc985da7d5e4140f593`다. 기능 변경과 목록 갱신을 함께 Git에 전달한다. 운영 반영·최종 확인은 아직 진행 중이며 완료 후 아래에 결과를 기록한다. 기존 승인된 Git 경로로 양쪽 자동배포를 시작하고, 관리영역 조회 대신 실제 공개/편집의 새 스타일과 표시를 확인한다.
