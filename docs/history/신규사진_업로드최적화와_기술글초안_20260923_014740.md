# 신규 사진 업로드 최적화와 기술 설명 글 초안

- 요구사항: `DWNC-CORE-031`, `PLAN-09`.
- 상태: 2026-09-23 실행 요청·완료조건 등록. 구현·실제 브라우저 검증·배포·미공개 초안 저장은 진행 중이다.

## 목표와 실행 범위

사용자가 앞선 투명도·압축 검토에 “그렇게 처리해줘”라고 실행을 요청했고 별도로 브라우저 기술 원리의 블로그 글 작성도 요청했다. 신규 업로드 기능과 실제 미공개 글 초안의 두 결과를 완성한다. 기존 사진 전수 변환·삭제나 Google 포토 설정·요금제 변경으로 범위를 넓히지 않는다.

첨부와 클립보드의 공통 업로드 경로에서 정지 불투명 이미지를 JPEG로 재압축하고 최대 16MP 이내로 비율을 유지한다. 실제 투명 PNG·애니메이션을 보존하고 작게 압축된 입력을 불필요하게 키우지 않는다. 사용자 로컬 파일을 바꾸지 않으며 업로드할 결과 바이트의 MIME·크기·SHA-256을 일치시킨다. JPEG 품질은 실제 브라우저 시험 후 확정하고 평균 약 1MB를 보장값으로 설명하지 않는다.

## 역할·자료와 완료 확인

코드 담당은 공통 업로드와 회귀, 글 담당은 원고·필요 도식, 메인은 사용자 세션의 브라우저·통합·Git 배포·운영 읽기 및 실제 초안 저장을 맡는다. 문서 담당은 공식 상태·완료조건·결과를 갱신한다.

관련 회귀와 로컬 실제 canvas로 품질·크기·해상도·투명도·애니메이션·입력 경로를 확인한 뒤 최종 빌드와 양쪽 Git 자동 배포·운영 읽기를 마친다. 신규 기능 시험은 로컬에서 우선하며 기존 실제 글을 시험 수정하지 않는다.

기술 설명 글은 구현 결과와 확인 한계를 반영해 필요한 도식과 함께 미공개 초안으로 저장하고 공개하지 않는다. 작성 자료 위치는 Git 제외 `migration/private/upload_optimization_article_20260923/`다. 이는 사용자 요청 콘텐츠 작성으로 기존 비공개 합성 시험 글과 구분한다. 개인 초안 본문은 공식 문서나 공개 저장소에 옮기지 않는다.

정책 검토는 [기존 참고 문서](../사진저장_조회비용_20260923_005427.md), 현재 완료조건은 [요구사항](../REQUIREMENTS.md), 다음 행동은 [공식 상태](../../PROJECT_STATE.md)를 따른다. 운영 기준선과 글 개수는 새 조회·배포 결과가 전달되기 전에는 갱신하지 않는다.

## 구현 정책과 현재 확인 단계

`src/lib/admin-image-upload.ts`의 공통 준비 로직을 읽고 미디어 계약에 반영했다. 정지 불투명 입력의 JPEG 품질은 `0.85`, 최대 화소는 16,000,000이며 비율을 유지하고 확대하지 않는다. 축소하지 않은 JPEG 결과가 입력 이상이면 작은 불투명 PNG를 포함해 원본 입력을 사용해 팽창을 막는다. 이번 기록 시점에는 실제 브라우저·빌드 검증 중이며 품질 시험과 운영 배포 완료로 판정하지 않는다.

JPEG 외 이미지의 알파는 원래 해상도에서 최대 1024×1024 타일로 검사한다. 실제 투명 PNG는 16MP 이내면 바이트를 유지하고 초과 시 PNG로 축소하며 다른 정지 투명 이미지는 PNG로 출력한다. 16비트 PNG의 알파/tRNS는 canvas의 8비트 반올림 오판을 피하려고 원형을 보존한다. GIF·APNG·애니메이션 WebP·애니메이션/시퀀스 AVIF도 원형을 유지한다. 정지 AVIF 전체를 무조건 제외하는 정책은 아니다.

입력 25MiB 한도와 오류 시 해당 파일 미업로드를 유지하고 최종 파일의 MIME·이름·바이트 수·SHA-256이 업로드 결과와 맞도록 연결한다. 기존 사진 일괄 변환·삭제는 없으며 글 초안의 실제 내용과 개인 사진 자료는 이 기록에 포함하지 않는다.

## 로컬 실제 브라우저 변환 확인

메인이 내장 브라우저의 로컬 fixture에서 실제 canvas 변환을 확인했다. 불투명 PNG는 309,108바이트에서 JPEG 50,544바이트로, JPEG는 119,170바이트에서 46,734바이트로 줄었다. EXIF 방향 6 입력은 256×384로 올바르게 향했고 실제 투명 PNG는 원형, 투명 WebP·AVIF는 투명 PNG로 유지됐다. GIF·APNG·애니메이션 WebP는 원형을 유지했다.

24MP(6000×4000) 입력은 4898×3265로 줄어 16MP 이하를 충족했고 JPEG 115,722바이트가 됐다. 깨진 입력에는 명확한 오류가 표시됐다. 이는 합성 패턴의 기능 시험이며 실제 사진이 평균 1MB로 줄어든다는 근거로 사용하지 않는다. 관련 회귀와 최종 소스 빌드는 이 기록 시점에 코드 담당이 진행 중이다.

## 기술 설명 글 준비

글 담당이 약 2,700자 원고와 1280×940 PNG 도식을 Git 제외 작성 자료 폴더에 준비했다. 메인은 실제 관리자에서 새 미공개 초안의 제목·분류를 준비 중이며 도식 첨부·본문 저장은 기능 배포 후 확인할 예정이다. 아직 운영 초안 본문 저장·도식 첨부 완료로 판정하지 않는다. 개인 초안의 실제 내용은 공식 문서에 옮기지 않는다.

## 최종 회귀·소스 빌드

신규 업로드·붙여넣기·UI 상태·작업본 관련 회귀와 최종 `cloudflare:build:source`를 통과했다(exit 0, Astro 오류 0). source bundle 공개 경로 1,425개와 기존 공개 요청 표면 해시는 유지됐고 비공개 자료 누출은 0이었다. 코드 담당 결과와 메인의 최종 로그 확인을 반영한 값이다. 앞선 빌드 대기 기록은 당시 진행 상태이며 현재는 통과했다. 운영 배포·운영 읽기와 실제 미공개 초안의 본문·도식 저장은 아직 대기 중이다.
