# 사진 번호 표시와 숫자로 순서 이동

작성: 2026-10-04 KST. `DWNC-CORE-038`, `PLAN-09`.

## 요청과 동작

휴대폰과 AI가 드래그 없이 사진 위치를 변경하도록 본문 사진의 현재 순서를 번호로 표시한다. 기존에는 드래그와 이동 버튼의 방향키 조작이 있었지만 최종 순번 입력은 없었다.

- 사진 번호 또는 사진을 눌러 선택하고 `옮길 번호`에 최종 순번을 입력한 뒤 `번호로 이동`을 누른다. Enter도 같은 동작이다. 이동 뒤 모든 번호를 다시 계산한다.
- 같은 그룹 안에서는 재정렬한다. 다른 그룹의 내부 순번으로 이동하면 그 경계에서 행을 나누고 독립 사진으로 놓는다. 공통 설명은 원래 앞쪽 행에, 개별 설명은 해당 사진에 보존한다. 분리와 이동은 한 번의 실행 취소로 되돌린다.
- 번호 배지는 편집 본문 밖의 도구다. 저장·미리보기·공개 본문에 들어가지 않는다. 사진 추가/삭제/이동/실행 취소/재열기와 스크롤·화면 변화에 따라 갱신한다.
- 유효 범위의 정수만 이동하고 동일 순번은 본문 변경 없이 안내한다. 글이나 표 하나에 여러 사진이 섞인 내부 위치는 원래 서식을 보존하기 위해 이동을 거부하고 별도 사진 문단으로 분리하도록 안내한다. 일반 첨부 사진과 사진 그룹은 지원한다.
