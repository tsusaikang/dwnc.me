# 글 전체 사진 순서 미리보기

작성: 2026-10-04 KST. `DWNC-CORE-039`, `PLAN-09`.

## 사용자 동작과 범위

사진을 선택하고 `전체 사진 순서`를 누르면 글 전체의 현재 사진 번호와 축소 미리보기를 볼 수 있다. 그룹 사진은 같은 줄로 표시하고, 사진 전체를 잘리지 않게 보여 준다. 이동할 사진은 파란 테두리와 문구로 구분한다. 원하는 최종 번호의 사진을 누르면 창을 닫고 `옮길 번호`에 해당 순번만 채운다. 실제 이동은 기존 `번호로 이동` 또는 입력칸 Enter로 실행한다.

모달은 본문 밖에 둬 저장·공개 본문과 실행 취소 이력을 바꾸지 않는다. 사진 URL·번호·그룹 변경을 갱신하고 URL 카드 썸네일은 제외한다. 닫기·Escape·입력칸 또는 열기 버튼으로 포커스 복귀를 지원한다. 기존 번호 이동·그룹 분리·사진 설명과 주변 본문 보존 정책을 그대로 이용한다. 다른 대기 요구사항은 시작하지 않았다.

## 구현과 확인

주요 구현은 하위 에이전트, 독립 읽기 검토는 별도 하위 에이전트가 수행했다. 메인은 통합·공식 기록·브라우저 시험·Git 전달을 맡았다. 사용자 세션이 필요한 운영 조회와 자체 브라우저 조작은 메인이 직접 수행했다.

- `src/lib/admin-image-direct.ts`: 본문 밖 native dialog, 전체 순서·그룹 행·선택 표시·번호 채우기·변화 감지·모바일 스타일.
- `src/lib/admin-ui.ts`: dialog 클릭·Escape에서 선택 사진을 유지한다.
- `scripts/test-image-direct.mjs`: 그룹 행·순번·원본 선택·목표 번호만 채움·이동/undo·URL/순서 최신화·busy·글 전환/삭제 방어·카드 제외·UI의 본문 제외·포커스 회귀.
- `npm run editor:test`와 독립 코드 검토 통과. `npm run cloudflare:build:source` 통과(진단·공개 소스 전용 산출물·배포 묶음 포함). 빌드의 과거 정적 자료는 빌드 계약 검사이며 최신 운영 콘텐츠 조사로 취급하지 않는다.
- 자체 브라우저 합성 글: 4번 미리보기 선택 후 본문 순서 불변·입력4/입력 포커스,1→4 이동과 한 번 undo, 자동저장 후 재열기에서 원순서·설명4개·본문에 미리보기 UI 없음 확인.
- 390×844px에서 창366×820px, 좌우12px 여백·가로넘침없음·내부스크롤·사진 contain 확인. 목록 끝 키보드 접근과 Escape 후 열기 버튼 포커스·사진 선택 유지 확인. 실제 휴대폰 터치·OS 화면 키보드는 미시험이다.
