# 신규 기능 요구사항

작성: 2026-09-11 KST · `DWNC-CORE-013` · `PLAN-09` · 상태: 로컬 구현·검증 완료 / 운영 미반영

현재 요청한 신규 기능만 기록한다. 완료 시 이 문서를 보관 영역으로 이동하고 현재 요구사항에서 완료 항목을 제거한다. 기존 결함 6건은 [결함 보완 요구사항](결함_보완_요구사항_20260909_223512.md)에 두며 착수 대기를 유지한다.

## 목적과 범위

편집기에서 사진을 좌·중·우로 정렬하고 표시 폭을 선택하며 사진 2개 또는 3개를 한 줄에 배치한다. 사용자 요청에 따른 로컬 구현·검증을 마쳤다. 기존 글·서식·사진·작업본·공개 주소와 미디어 소유·접근 정책은 유지한다.

## 세부 요구사항과 인수 조건

| ID | 기능 | 인수 조건 |
|---|---|---|
| I01 | 이미지 정렬 | 선택한 사진의 왼쪽·가운데·오른쪽 정렬을 도구에서 선택한다. 설정이 편집 화면·저장 후 재열기·미리보기·공개 렌더링에 같은 의미로 유지된다. |
| I02 | 이미지 표시 폭 | 원본 100%·문단 폭·전체 폭을 선택하되 원본 픽셀 너비보다 크게 확대하지 않는다. 필요한 폭을 채우지 못하는 선택지는 비활성화하고 이유를 안내한다. 두 폭 모두 원본보다 크거나 원본 크기를 아직 읽지 못했으면 100%만 선택할 수 있다. 비율을 유지하고 화면보다 넓은 사진은 넘치지 않는다. |
| I03 | 한 줄 사진 배열 | 본문에서 연속된 사진 2개 또는 3개를 선택해 한 줄로 묶으며 본문의 기존 사진 순서를 유지한다. 그룹을 해제해 개별 사진으로 되돌릴 수 있다. 사진마다 원본 비율을 유지하고 각 칸의 필요 폭을 각 원본 픽셀 너비와 비교해 확대하지 않는다. 좁은 화면에서 가로 넘침 없이 읽을 수 있게 배치한다. |
| I04 | 편집 이력과 저장 | 정렬·표시 폭·그룹 묶기·해제는 실행 취소·다시 실행할 수 있다. 저장 후 재열기에서도 사진 순서·정렬·폭·그룹을 유지하며 작업본 자동저장이 공개본을 바꾸지 않는다. |
| I05 | 기존 내용 보존 | 원본 파일을 변형·덮어쓰거나 기존 글을 일괄 변경하지 않는다. 그룹 구성 때문에 사진 사이의 본문을 이동하지 않는다. 기존 본문의 표시와 사진 소유권·비공개/예약/보호 접근 정책을 유지한다. |

### 표시 폭과 확대 금지

- **원본 100%:** 이미지 고유 폭을 기준으로 표시하되 화면의 가용 폭을 넘지 않는다.
- **문단 폭:** 최대 720px인 본문 문단 폭에 맞춘다. 선택 가능 여부는 좁은 화면에서도 720px을 기준으로 판정한다.
- **전체 폭:** 최대 1200px인 넓은 가용 영역에 맞춘다. 선택 가능 여부는 좁은 화면에서도 1200px을 기준으로 판정하며 실제 표시는 화면 폭을 넘지 않는다.

2026-09-11 사용자 추가 조건으로 확정했다. 문단 폭·전체 폭에 필요한 픽셀 너비가 원본보다 크면 해당 선택지를 비활성화하고 이유를 안내한다. 두 선택지 모두 확대가 필요하면 원본 100%만 허용한다. 원본 크기를 아직 읽지 못한 동안도 100%만 허용한다. 그룹은 각 사진이 들어갈 칸의 필요 폭을 해당 원본과 비교해 같은 확대 금지 원칙을 적용한다.

## 완료 조건과 검증 범위

- I01~I05 구현과 관련 합성 시험을 통과한다. 다른 비율·크기 사진, 2개/3개 배열, 저장 후 재열기, 미리보기·공개 렌더링, 실행 취소·다시 실행 및 좁은 화면을 확인한다.
- 메인이 내장 브라우저에서 로컬 합성 콘텐츠로 실제 조작과 표시를 확인한다. 실제 운영 글·사진은 시험 수정·삭제하지 않는다.
- 구현·합성 시험·로컬 브라우저 확인과 운영 반영 상태를 구분한다. 2026-09-11 사용자가 “그냥 배포해주라”로 이번 신규 기능의 운영 반영을 명시 승인했다. 기존 Git 자동 배포 경로에서 최종 소스를 새로 빌드해 반영하고 확인한다.
- raw 배포·DNS/route 변경·R2 덮어쓰기/삭제를 하지 않는다. 비밀값과 비공개 콘텐츠를 기록하거나 공개 빌드에 포함하지 않는다.

## 현재 확인 상태

로컬 구현과 `editor:test`·`check`, 내장 브라우저 조작 확인을 완료했다. 사진 정렬·폭·2개/3개 그룹·해제와 원본 확대 금지를 제공한다. 이번 명시 승인에 따라 Git 전달·운영 반영을 진행하며 아직 완료를 판정하지 않았다. 실제 반영 결과와 다음 행동은 [공식 상태](../PROJECT_STATE.md)에서 관리한다.

검증은 합성 콘텐츠로 진행했다. 본문의 정확한 보존과 실행 취소/다시 실행, 줄바꿈·문자 입력·굵게·사진 배치를 섞은 이력과 새 입력 분기를 확인했다. 3열 배열의 PC/모바일 미리보기에서 넘침이 없었고, 1000px 원본을 1000px로 표시했다. 저장 후 재열기의 3열 유지와 그룹 해제 후 개별 원래 크기 복원은 내장 브라우저 접근성 상태·실제 화면으로 확인했다. 재열기 후 DOM의 정확한 재비교는 연결 시간 초과로 실행하지 않았다. 실제 IME 입력과 운영체제 메뉴의 실행 취소는 직접 확인하지 않았으며 관련 입력 경로는 합성 시험 근거만 있다.
