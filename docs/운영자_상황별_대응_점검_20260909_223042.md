# 블로그 운영자 상황별 대응 점검

점검일: 2026-09-09 · 대상: 현재 dwnc.me 공개 사이트와 관리자 · 요청 범위: 확인만

## 결론

**점검은 완료했지만, 현재 블로그가 어떤 경우에도 모두 대응하는 상태는 아니다.** 일상적인 작성·작업본 저장·공개 반영·비공개 관리·예약·보호·목록·기본 설정은 대응한다. 반면 아래 재현 결함, 복구·백업·삭제 등의 미지원 기능, 실제 장치와 큰 장애에서의 미확인 영역이 남아 있다. 이번에는 수정·배포하지 않았다.

운영 상황 **119개(A 37개, L 43개, O 39개)**를 아래 표에 명시했다. 같은 기능이 작성자/관리자/방문자 관점에서 중복 등장할 수 있으므로 119는 독립 기능 수나 품질 점수가 아니다. 글·페이지·공지 각각의 상태 전환 **60분기**도 별도 행렬로 확인했다.

무한한 기기·입력·동시 작업·장애의 모든 조합을 유한한 점검으로 보증할 수는 없다. 이 표는 정상 흐름뿐 아니라 입력 한계, 실패, 재시도, 취소·복구, 접근 권한, 이전 자료, 장기 보관을 명시한 현재 대응 범위다. 표의 '지원'도 명시된 검증 수준과 제한 안에서의 판정이다.

## 이번 확인 방법과 범위

- 현재 소스와 공식 요구사항·미디어 계약을 대조하고 기존 합성 시험을 실행했다. 글·페이지·공지의 상태 전환60분기도 합성 DB로 실행했다.
- 실제 공개 화면에서 홈, 검색 결과, 결과 없음 안내, 전체 글349개 연결을 확인했다. 로그인한 새 관리자 탭에서 전체596편과 비공개247편, 필터와 기본 관리 메뉴를 내용 출력 없이 확인했다.
- 합성 글의 사진1개 → 이미지 삭제 후0개 → 실행 취소 후에도0개를 내장 브라우저로 재현했다. 검색 통신 실패/늦은 응답은 실제 검색 소스에 합성 통신을 연결하여 재현했다. 비공개 사진 공개전환 문제는 합성 DB에서 재현했다.
- 실제 글·작업본·설정·사진을 변경하지 않았고, 실제 장애·부하·삭제·복구·권한 변경·배포는 실행하지 않았다. 새 글 작성이나 사진 첨부 시험도 실제 운영 자료에는 하지 않았다.
- 과거 운영 화면 확인을 근거로 한 항목은 표에 구분했다. 실제 모바일 기기·다른 브라우저·스크린리더·검색엔진과 SNS의 외부 수집 결과·계정/비용 알림은 이번에 검증한 것으로 표시하지 않는다.
- 아래 '제한'에는 기능 미지원 외에도 빈 글 발행 거절처럼 의도적으로 허용하지 않는 입력 범위가 포함된다. 제한을 모두 결함으로 해석하지 않는다. '미확인'도 곧 실패한다는 뜻은 아니다.

# 작성·편집 운영 시나리오 감사

2026-09-09. 소스 읽기 및 합성 자료 시험만 수행. 운영 글 수정·저장·발행·삭제·배포 없음. AGENTS.md, PROJECT_STATE.md 최신 완료, REQUIREMENTS의 CORE-002~011을 기준으로 현재 소스를 대조했다. 무한한 모든 조합의 보증이 아니라 실용적 대표 경우를 명시한다.

판정: **지원**=소스와 시험/기존 실측 근거 있음, **제한**=기능 부재 또는 명시된 허용 범위, **결함**=실패 경로에 현재 구현의 구체적 빈틈, **미확인**=브라우저/장치 실측 등 증거 부족. 최신 운영 확인은 공식 상태의 기록이며 이번 감사에서 운영을 다시 조작한 것은 아니다.

## 먼저 확인할 결과

- 브라우저 강제 종료·모바일 앱 제거·운영체제 재시작 후 미저장 입력 복구는 지원하지 않는다. 입력은 현재 화면 메모리에만 있고 경고는 beforeunload뿐이다. 온라인 자동저장 성공분은 남지만 0.8초 지연/요청 중/실패 후 입력은 잃을 수 있다.
- 작업본의 과거 버전 보기/되돌리기, 공개본으로 작업본 되돌리기 기능이 없다. 현재 작업본과 공개본 분리는 과거 이력 저장과 다르다.
- 신규 HEIC·SVG·MP4·PDF/ZIP 첨부는 지원하지 않는다. 기존 이전 SVG/ICO/MP4 읽기 보존은 별도이며 신규 첨부 기능을 뜻하지 않는다.
- 서버에서 새 초안을 만들었으나 응답만 유실된 뒤 다시 시도하면 새 빈 초안이 추가된다. 동일 업로드 응답 유실 재시도도 별도 UUID 사진을 추가할 수 있다. 원본 덮어쓰기는 없으나 정확히 한 번 처리되지 않는다.
- 사진 삭제 후 실행취소는 **확정 결함**이다. 메인 합성 브라우저에서 본문 사진 1개→이미지 삭제 후 0개→실행취소 후에도 0개로 복원되지 않음을 재현했다. HTML 소스 붙여넣기 실행취소는 별도이며 여전히 미확인이다. 실제 글은 변경하지 않았다.

## 명시적 상태 전환 행렬

다음 표를 **글/페이지/공지 각각** 적용하여 총60분기를 합성 실행했다. P=공개, V=비공개, S=미래예약, K=보호. 각 칸은 PASS이며 '번호유지'는 기존 번호가 있는 경우이다. 공개 표시·CSS·카테고리·시간대 등 실제 표시 조건은 위 시나리오의 제한을 같이 적용한다.

| 출발 | →P | →V | →S | →K |
|---|---|---|---|---|
| 초안 | 첫번호 발행 | 첫번호 비공개 | 첫번호+미래시각 | 첫번호+새암호 |
| 공개 | 번호유지 갱신 | 번호유지 비공개 | 번호유지+미래시각 | 번호유지+새암호 |
| 비공개 | 번호유지 공개 | 번호유지 갱신 | 번호유지+미래시각 | 번호유지+새암호 |
| 예약 | 번호유지 즉시공개 | 번호유지 예약취소 | 번호유지 재예약 | 번호유지+새암호 |
| 보호 | 번호유지 공개 | 번호유지 비공개 | 번호유지+미래시각 | 번호유지 암호갱신/유지 |

→초안 복귀는 제공하지 않음. 내용 공개 중단은 비공개 전환. '공개 상태·예약' 적용은 저장한 최신 작업본도 함께 반영하며, 상태만 바꾸면서 이전 반영본을 그대로 선택하는 별도 동작은 없음. 보호 세션은 반영 때 무효화한다.

주요 결론: 일반적인 콘텐츠 생애주기는 지원하지만 모든 운영 상황에 대응한다고 말할 수 없다. 확정 결함은 이관 글 CSS 배경전용 미디어의 독자 제공 누락이고, 일반 삭제/휴지통/과거이력복원/일괄관리/미사용첨부정리/고급통계는 현재 제품 기능 범위 밖이다. 백업·복구/운영 장애는 아래 운영 분야 표에서 다룬다.
